SERVICE DECISION RECORDS (SDR)

SDR-STG-001: Neo4j as Primary Story Graph Database



Decision: Use Neo4j Enterprise 5.x as the primary Story Graph database with causal clustering
for high availability. PostgreSQL stores operational metadata; MongoDB stores full content
snapshots.

Rationale: Neo4j's native graph engine is purpose-built for relationship-heavy workloads like
story evolution, entity linking, and provenance tracking. Graph traversals that would require
complex SQL joins are expressed naturally in Cypher. Causal clustering provides the write
consistency required for editorial workflows.

Alternatives: PostgreSQL with recursive CTEs (rejected — performance degrades beyond 3-hop
traversals); Amazon Neptune (rejected — vendor lock-in, higher cost); ArangoDB (rejected —
smaller ecosystem).

Trade-offs: Additional operational complexity managing Neo4j alongside PostgreSQL/MongoDB,
but graph query performance is 10-100x better for story relationship queries.



SDR-STG-002: Event-Sourced Story Versioning



Decision: Every story mutation is recorded as an immutable event in Kafka, with materialized
views in Neo4j and PostgreSQL. Story versions are derived from event replay, not direct
mutation.

Rationale: Event sourcing provides complete audit trail, enables time-travel queries, supports
conflict resolution, and allows rebuilding any historical state. Essential for editorial provenance.

Alternatives: Traditional CRUD with version columns (rejected — no event history, harder
conflict resolution); Git-like branching model (rejected — overcomplicated for editorial
workflows).

Trade-offs: Increased storage for event log, but essential for editorial integrity and regulatory
compliance.



SDR-STG-003: pgvector for Embedding Storage with Neo4j for Graph Traversal

Decision: Store document and entity embeddings in PostgreSQL with pgvector for ANN
similarity search. Store graph relationships in Neo4j. Combine both via a hybrid search service.

Rationale: pgvector provides production-grade vector search within existing PostgreSQL
infrastructure. Neo4j handles graph-specific queries. Hybrid approach leverages each database's
strengths.

Alternatives: Neo4j with graph embeddings only (rejected — vector search less mature);
dedicated vector DB like Pinecone (rejected — additional infrastructure).

Trade-offs: Two systems to query for hybrid search, but each optimized for its domain.



SDR-STG-004: CQRS for Story Read/Write Separation



Decision: Implement Command Query Responsibility Segregation (CQRS) for stories. Commands
(create, update, merge) write through the domain model and publish events. Queries read from
optimized materialized views.

Rationale: Story graph queries are complex and read-heavy. CQRS allows optimizing reads
independently from writes, scaling read replicas, and building specialized query models.

Alternatives: Single model for reads and writes (rejected — query performance suffers under
write load).

Trade-offs: Eventual consistency between write and read models, but acceptable for story
content (seconds of lag).

func NewStoryStateMachine(story *CanonicalStory, eventStore EventStore) *StoryStateMachine
{

    sm := &StoryStateMachine{

        story:      story,

        currentState: story.State,

        eventStore: eventStore,

    }



    sm.transitions = map[StoryState]map[StoryEvent]StoryState{

        StoryStateDiscovered: {

             EventCandidateAccepted: StoryStateCandidate,

             EventDuplicateDetected: StoryStateDiscovered, // Will be merged

             EventBreakingDeclared: StoryStateBreaking,

        },

        StoryStateCandidate: {

             EventCandidateRejected: StoryStateClosed,

             EventVerificationPassed: StoryStateVerified,

        },

StoryStateVerified: {

     EventNewInformationAdded: StoryStateDeveloping,

     EventBreakingDeclared: StoryStateBreaking,

     EventStoryClosed:      StoryStateClosed,

},

StoryStateDeveloping: {

     EventVerificationPassed: StoryStateVerified,

     EventUpdatePublished:    StoryStateActive,

     EventStoryClosed:      StoryStateClosed,

},

StoryStateActive: {

     EventNewInformationAdded: StoryStateDeveloping,

     EventCorrectionIssued: StoryStateCorrecting,

     EventStoryClosed:      StoryStateClosed,

     EventStoryArchived:     StoryStateArchived,

},

StoryStateBreaking: {

     EventNewInformationAdded: StoryStateDeveloping,

     EventUpdatePublished:    StoryStateActive,

     EventCorrectionIssued: StoryStateCorrecting,

},

StoryStateCorrecting: {

     EventUpdatePublished:    StoryStateActive,

     EventStoryRetracted:    StoryStateRetracted,

},

StoryStateClosed: {

             EventStoryReopened:    StoryStateDeveloping,

             EventStoryArchived:   StoryStateArchived,

        },

        StoryStateArchived: {

             EventStoryReopened:    StoryStateDeveloping,

        },

        StoryStateRetracted: {

             // Terminal state

        },

    }



    return sm

}



func (sm *StoryStateMachine) Transition(event StoryEvent, metadata map[string]interface{})
error {

    validEvents, exists := sm.transitions[sm.currentState]

    if !exists {

        return fmt.Errorf("no transitions from state: %s", sm.currentState)

    }



    nextState, valid := validEvents[event]

    if !valid {

        return fmt.Errorf("invalid transition: %s -[%s]-> ?", sm.currentState, event)

    }

      // Record event

      domainEvent := NewStoryDomainEvent(

          sm.story.StoryID,

          event,

          sm.currentState,

          nextState,

          metadata,

      )



  if err := sm.eventStore.Append(sm.story.EventStreamID, domainEvent,
sm.story.EventVersion); err != nil {

          return fmt.Errorf("append event: %w", err)

      }



      // Update state

      sm.currentState = nextState

      sm.story.State = nextState

      sm.story.EventVersion++

      sm.story.LastUpdatedAt = time.Now()

      sm.story.Version++



      return nil

}

// ExecuteMerge performs a story merge operation

func (sme *StoryMergeEngine) ExecuteMerge(

    ctx context.Context,

    request *MergeRequest,

) (*MergeResult, error) {



    // 1. Load both stories with all relationships

    sourceStory, err := sme.loadFullStory(ctx, request.SourceStoryID)

    if err != nil {

        return nil, fmt.Errorf("load source story: %w", err)

    }



    targetStory, err := sme.loadFullStory(ctx, request.TargetStoryID)

    if err != nil {

        return nil, fmt.Errorf("load target story: %w", err)

    }



    // 2. Validate merge is appropriate

    if err := sme.validateMerge(sourceStory, targetStory); err != nil {

        return nil, fmt.Errorf("merge validation: %w", err)

    }

  // 3. Calculate similarity and detect conflicts

  similarity := await sme.similarityEngine.CalculateSimilarity(ctx, sourceStory, targetStory)

  conflicts := sme.detectConflicts(sourceStory, targetStory)



  result := &MergeResult{

       MergeID:      uuid.NewV7(),

       SourceStoryID: request.SourceStoryID,

       TargetStoryID: request.TargetStoryID,

       Strategy:    request.MergeStrategy,

       ConflictsFound: conflicts,

       Status:     MergeStatusInProgress,

  }



  // 4. If conflicts exist and strategy is COMBINE, escalate to human

  if len(conflicts) > 0 && request.MergeStrategy == MergeStrategyCombine {

       return sme.escalateToHumanReview(ctx, result, sourceStory, targetStory, conflicts)

  }



  // 5. Execute merge in Neo4j transaction

  session := sme.neo4jClient.NewSession(ctx, neo4j.SessionConfig{

       AccessMode: neo4j.AccessModeWrite,

  })

  defer session.Close(ctx)



  changes, err := session.ExecuteWrite(ctx, func(tx neo4j.ManagedTransaction) (interface{},
error) {

    return sme.executeMergeTransaction(ctx, tx, sourceStory, targetStory,
request.MergeStrategy, conflicts)

  })

  if err != nil {

       result.Status = MergeStatusFailed

       return result, fmt.Errorf("execute merge transaction: %w", err)

  }



  result.ChangesApplied = changes.([]MergeChange)



  // 6. Determine result story

  switch request.MergeStrategy {

  case MergeStrategyAbsorb:

       result.ResultStoryID = request.TargetStoryID

  case MergeStrategySupersede:

       result.ResultStoryID = request.SourceStoryID

  case MergeStrategyCombine:

       result.ResultStoryID = request.TargetStoryID // Updated target

  }



  // 7. Record merge events

  sme.recordMergeEvents(ctx, result)



  // 8. Update source story state

  sme.closeSourceStory(ctx, request.SourceStoryID, request.TargetStoryID)

    result.Status = MergeStatusCompleted

    result.CompletedAt = time.Now()



    return result, nil

}



func (sme *StoryMergeEngine) executeMergeTransaction(

    ctx context.Context,

    tx neo4j.ManagedTransaction,

    source *CanonicalStory,

    target *CanonicalStory,

    strategy MergeStrategy,

    conflicts []MergeConflict,

) ([]MergeChange, error) {



    changes := []MergeChange{}



    // 1. Move all claims from source to target

    result, err := tx.Run(ctx, `

      MATCH (source:Story {story_id: $sourceId})

      MATCH (source)-[:CONTAINS_CLAIM]->(claim:Claim)

      MATCH (target:Story {story_id: $targetId})

     CREATE (target)-[:CONTAINS_CLAIM {merged_from: $sourceId, merged_at: datetime()}]-
>(claim)

      RETURN count(claim) as claim_count

    `, map[string]interface{}{

     "sourceId": source.StoryID.String(),

     "targetId": target.StoryID.String(),

})



if err == nil && result.Next() {

     count := result.Record().Values[0].(int64)

     changes = append(changes, MergeChange{

          ChangeType: "MOVE_CLAIMS",

          Description: fmt.Sprintf("Moved %d claims from source to target", count),

     })

}



// 2. Link all sources from source story to target

result, err = tx.Run(ctx, `

     MATCH (source:Story {story_id: $sourceId})-[r:SOURCED_FROM]->(src:Source)

     MATCH (target:Story {story_id: $targetId})

     CREATE (target)-[:SOURCED_FROM {

          relevance: r.relevance,

          merged_from: $sourceId

     }]->(src)

     RETURN count(src) as source_count

`, map[string]interface{}{

     "sourceId": source.StoryID.String(),

     "targetId": target.StoryID.String(),

})

if err == nil && result.Next() {

     count := result.Record().Values[0].(int64)

     changes = append(changes, MergeChange{

          ChangeType: "LINK_SOURCES",

          Description: fmt.Sprintf("Linked %d sources to target story", count),

     })

}



// 3. Link all entities

result, err = tx.Run(ctx, `

     MATCH (source:Story {story_id: $sourceId})-[r:INVOLVES_ENTITY]->(e:Entity)

     MATCH (target:Story {story_id: $targetId})

     MERGE (target)-[:INVOLVES_ENTITY {

          role: r.role,

          merged_from: $sourceId

     }]->(e)

     RETURN count(e) as entity_count

`, map[string]interface{}{

     "sourceId": source.StoryID.String(),

     "targetId": target.StoryID.String(),

})



if err == nil && result.Next() {

     count := result.Record().Values[0].(int64)

     changes = append(changes, MergeChange{

          ChangeType: "LINK_ENTITIES",

          Description: fmt.Sprintf("Linked %d entities to target story", count),

     })

}



// 4. Create MERGED_INTO relationship

_, err = tx.Run(ctx, `

     MATCH (source:Story {story_id: $sourceId})

     MATCH (target:Story {story_id: $targetId})

     CREATE (source)-[:MERGED_INTO {

          strategy: $strategy,

          merged_at: datetime()

     }]->(target)

     SET source.state = 'CLOSED',

          source.last_updated_at = datetime()

     SET target.source_count = target.source_count + source.source_count,

          target.claim_count = target.claim_count + source.claim_count,

          target.last_updated_at = datetime(),

          target.version = target.version + 1

`, map[string]interface{}{

     "sourceId": source.StoryID.String(),

     "targetId": target.StoryID.String(),

     "strategy": string(strategy),

})



if err != nil {

     return nil, fmt.Errorf("create merge relationship: %w", err)

    }



    changes = append(changes, MergeChange{

         ChangeType: "MERGE_RELATIONSHIP",

         Description: "Created MERGED_INTO relationship and updated story states",

    })



    return changes, nil

}



func (sme *StoryMergeEngine) detectConflicts(

    source *CanonicalStory,

    target *CanonicalStory,

) []MergeConflict {

    conflicts := []MergeConflict{}



    // Headline conflict (different headlines for same event)

    if source.Headline != target.Headline &&

         sme.headlinesAreSubstantiallyDifferent(source.Headline, target.Headline) {

         conflicts = append(conflicts, MergeConflict{

              ConflictType: "HEADLINE",

              Field:   "headline",

              SourceValue: source.Headline,

              TargetValue: target.Headline,

              Resolution: "KEEP_TARGET", // Default: keep more established story's headline

         })

    }



    // Category conflict

    if source.Category != target.Category {

        conflicts = append(conflicts, MergeConflict{

             ConflictType: "CATEGORY",

             Field:    "category",

             SourceValue: source.Category,

             TargetValue: target.Category,

             Resolution: "MANUAL",

        })

    }



    // Priority conflict

    if source.Priority != target.Priority {

        conflicts = append(conflicts, MergeConflict{

             ConflictType: "PRIORITY",

             Field:    "priority",

             SourceValue: source.Priority,

             TargetValue: target.Priority,

             Resolution: "KEEP_HIGHEST",

        })

    }



    return conflicts

}

class EntityResolutionEngine:

      """Resolves entity mentions to canonical entities."""



      def __init__(self, neo4j_driver, wikidata_client, embedding_model):

        self.neo4j = neo4j_driver

        self.wikidata = wikidata_client

        self.embedding_model = embedding_model

async def resolve(

  self,

  name: str,

  entity_type: str,

  context: Optional[str] = None,

) -> ResolvedEntity:

  """

  Resolve an entity mention to its canonical form.

  Uses: 1) Exact match in graph, 2) Wikidata lookup, 3) Embedding similarity

  """



  # 1. Try exact match in existing graph

  async with self.neo4j.session() as session:

    result = await session.run("""

          MATCH (e:Entity)

          WHERE e.canonical_name = $name OR $name IN e.aliases

          RETURN e

          LIMIT 1

    """, {"name": name.lower().strip()})



    record = await result.single()

    if record:

          entity = record["e"]

          return ResolvedEntity(

            entity_id=entity["entity_id"],

        canonical_name=entity["canonical_name"],

        name=entity["name"],

        entity_type=entity["entity_type"],

        resolution_method="GRAPH_EXACT_MATCH",

        confidence=1.0,

    )



# 2. Try Wikidata lookup

wikidata_result = await self.wikidata.search(name, entity_type)

if wikidata_result and wikidata_result.confidence > 0.9:

  # Check if Wikidata entity already in graph

  async with self.neo4j.session() as session:

    result = await session.run("""

        MATCH (e:Entity {wikidata_id: $wikidata_id})

        RETURN e

        LIMIT 1

    """, {"wikidata_id": wikidata_result.wikidata_id})



    record = await result.single()

    if record:

        entity = record["e"]

        return ResolvedEntity(

          entity_id=entity["entity_id"],

          canonical_name=entity["canonical_name"],

          name=entity["name"],

          entity_type=entity["entity_type"],

                resolution_method="WIKIDATA_GRAPH_MATCH",

                confidence=wikidata_result.confidence,

            )



      # Create new entity from Wikidata

      return ResolvedEntity(

          entity_id=str(uuid.uuid4()),

          canonical_name=wikidata_result.canonical_name,

          name=name,

          entity_type=entity_type,

          wikidata_id=wikidata_result.wikidata_id,

          description=wikidata_result.description,

          resolution_method="WIKIDATA_NEW",

          confidence=wikidata_result.confidence,

      )



    # 3. Try embedding similarity

    name_embedding = await self.embedding_model.embed(name)

    similar_entities = await self._find_similar_entities(name_embedding, entity_type,
threshold=0.85)



    if similar_entities:

      best_match = similar_entities[0]

      return ResolvedEntity(

          entity_id=best_match["entity_id"],

          canonical_name=best_match["canonical_name"],

                name=name,

                entity_type=entity_type,

                resolution_method="EMBEDDING_SIMILARITY",

                confidence=best_match["similarity"],

            )

// VersionEngine provides event-sourced story versioning

type VersionEngine struct {

// StoryEvent represents an immutable event in the story's lifecycle

type StoryEvent struct {

    EventID     uuid.UUID      `json:"event_id"`

    StreamID     string      `json:"stream_id"`

    EventVersion int64        `json:"event_version"`

    EventType StoryEventType `json:"event_type"`

    StoryID    uuid.UUID      `json:"story_id"`

    Data       json.RawMessage `json:"data"`

    Metadata     json.RawMessage `json:"metadata"`

    OccurredAt time.Time        `json:"occurred_at"`

    ActorID     string      `json:"actor_id"`

}



type StoryEventType string

const (

    EventTypeStoryCreated        StoryEventType = "STORY_CREATED"

    EventTypeHeadlineChanged StoryEventType = "HEADLINE_CHANGED"

    EventTypeSummaryChanged        StoryEventType = "SUMMARY_CHANGED"

    EventTypeClaimAdded         StoryEventType = "CLAIM_ADDED"

    EventTypeClaimRemoved        StoryEventType = "CLAIM_REMOVED"

    EventTypeSourceAdded        StoryEventType = "SOURCE_ADDED"

    EventTypeEntityLinked     StoryEventType = "ENTITY_LINKED"

    EventTypeStateChanged       StoryEventType = "STATE_CHANGED"

    EventTypePriorityChanged StoryEventType = "PRIORITY_CHANGED"

    EventTypeStoryMerged        StoryEventType = "STORY_MERGED"

    EventTypeStorySplit      StoryEventType = "STORY_SPLIT"

    EventTypeCorrectionApplied StoryEventType = "CORRECTION_APPLIED"

    EventTypeConfidenceUpdated StoryEventType = "CONFIDENCE_UPDATED"

)



// AppendEvent appends a new event to the story's event stream

func (ve *VersionEngine) AppendEvent(

    ctx context.Context,

    streamID string,

    expectedVersion int64,

    eventType StoryEventType,

    storyID uuid.UUID,

    data interface{},

    actorID string,

) (*StoryEvent, error) {



    dataJSON, _ := json.Marshal(data)

    event := &StoryEvent{

        EventID:     uuid.NewV7(),

        StreamID:     streamID,

        EventVersion: expectedVersion + 1,

        EventType: eventType,

        StoryID:    storyID,

        Data:       dataJSON,

        Metadata:     json.RawMessage(fmt.Sprintf(`{"actor_id":"%s"}`, actorID)),

        OccurredAt: time.Now(),

        ActorID:     actorID,

    }



    // Append with optimistic concurrency check

    if err := ve.eventStore.Append(ctx, streamID, event, expectedVersion); err != nil {

        return nil, fmt.Errorf("append event (version conflict): %w", err)

    }



    // Every N events, create a snapshot for faster replay

    if event.EventVersion%10 == 0 {

        ve.createSnapshot(ctx, streamID, event.EventVersion)

    }



    return event, nil

}



// RebuildStory rebuilds story state from events

func (ve *VersionEngine) RebuildStory(

  ctx context.Context,

  streamID string,

  targetVersion *int64,

) (*CanonicalStory, error) {



  // Try to load from latest snapshot first

  var story *CanonicalStory

  var fromVersion int64



  snapshot, err := ve.snapshotStore.LoadLatest(ctx, streamID)

  if err == nil && snapshot != nil {

      story = snapshot.State

      fromVersion = snapshot.Version

  } else {

      story = &CanonicalStory{} // Empty initial state

      fromVersion = 0

  }



  // Load events from after the snapshot

  events, err := ve.eventStore.Load(ctx, streamID, fromVersion+1, targetVersion)

  if err != nil {

      return nil, fmt.Errorf("load events: %w", err)

  }



  // Apply events to rebuild state

    for _, event := range events {

        ve.applyEvent(story, event)

    }



    story.EventVersion = fromVersion + int64(len(events))



    return story, nil

}



// applyEvent applies a single event to story state

func (ve *VersionEngine) applyEvent(story *CanonicalStory, event *StoryEvent) {

    switch event.EventType {

    case EventTypeStoryCreated:

        json.Unmarshal(event.Data, story)



    case EventTypeHeadlineChanged:

        var data struct {

            OldHeadline string `json:"old_headline"`

            NewHeadline string `json:"new_headline"`

        }

        json.Unmarshal(event.Data, &data)

        story.Headline = data.NewHeadline



    case EventTypeClaimAdded:

        story.ClaimCount++

    case EventTypeStateChanged:

        var data struct {

            OldState string `json:"old_state"`

            NewState string `json:"new_state"`

        }

        json.Unmarshal(event.Data, &data)

        story.State = StoryState(data.NewState)



    case EventTypeStoryMerged:

        var data struct {

            MergedStoryID string `json:"merged_story_id"`

        }

        json.Unmarshal(event.Data, &data)

        mergedID, _ := uuid.Parse(data.MergedStoryID)

        story.MergedFromIDs = append(story.MergedFromIDs, mergedID)



    // ... other event types

    }



    story.EventVersion = event.EventVersion

    story.LastUpdatedAt = event.OccurredAt

    story.Version++

}



// GenerateDiff generates a diff between two story versions

func (ve *VersionEngine) GenerateDiff(

      ctx context.Context,

      streamID string,

      fromVersion int64,

      toVersion int64,

) (*StoryDiff, error) {



      fromStory, err := ve.RebuildStory(ctx, streamID, &fromVersion)

      if err != nil {

          return nil, fmt.Errorf("rebuild from version: %w", err)

      }



      toStory, err := ve.RebuildStory(ctx, streamID, &toVersion)

      if err != nil {

          return nil, fmt.Errorf("rebuild to version: %w", err)

      }



      return ve.diffEngine.Compare(fromStory, toStory), nil

}

// DuplicateDetector identifies duplicate stories using multiple strategies

type DuplicateDetector struct {

    SemanticHigh        float64 `json:"semantic_high"`       // 0.92

    SemanticMedium        float64 `json:"semantic_medium"`        // 0.85

    EntityOverlapHigh    float64 `json:"entity_overlap_high"`   // 0.80

    CrossLingualThreshold float64 `json:"cross_lingual_threshold"` // 0.80

}



type DuplicateResult struct {

    SourceStoryID uuid.UUID          `json:"source_story_id"`

    IsDuplicate    bool         `json:"is_duplicate"`

    DuplicateType DuplicateType `json:"duplicate_type"`

    MatchedStoryID *uuid.UUID          `json:"matched_story_id,omitempty"`

    SimilarityScore float64       `json:"similarity_score,omitempty"`

    MatchDetails    []MatchDetail `json:"match_details,omitempty"`

    RecommendedAction string           `json:"recommended_action"` // MERGE, REVIEW, IGNORE

}



type DuplicateType string

const (

    DuplicateTypeNone           DuplicateType = "NONE"

    DuplicateTypeExact        DuplicateType = "EXACT"

    DuplicateTypeNearExact        DuplicateType = "NEAR_EXACT"

    DuplicateTypeSemantic        DuplicateType = "SEMANTIC"

    DuplicateTypeEntityBased DuplicateType = "ENTITY_BASED"

    DuplicateTypeCrossLingual DuplicateType = "CROSS_LINGUAL"

)



// DetectDuplicates performs multi-tier duplicate detection

func (dd *DuplicateDetector) DetectDuplicates(

    ctx context.Context,

    story *CanonicalStory,

) (*DuplicateResult, error) {



    result := &DuplicateResult{

    SourceStoryID: story.StoryID,

    IsDuplicate: false,

}



// Tier 1: Exact content hash match

if match, err := dd.checkExactHash(ctx, story); err == nil && match != nil {

    return &DuplicateResult{

       SourceStoryID:     story.StoryID,

       IsDuplicate:     true,

       DuplicateType:     DuplicateTypeExact,

       MatchedStoryID:     &match.StoryID,

       SimilarityScore: 1.0,

       RecommendedAction: "MERGE",

    }, nil

}



// Tier 2: Near-exact SimHash match

if match, err := dd.checkSimHash(ctx, story); err == nil && match != nil {

    return &DuplicateResult{

       SourceStoryID:     story.StoryID,

       IsDuplicate:     true,

       DuplicateType:     DuplicateTypeNearExact,

       MatchedStoryID:     &match.StoryID,

       SimilarityScore: match.Similarity,

       RecommendedAction: "MERGE",

    }, nil

}



// Tier 3: Semantic vector similarity

similarDocs, err := dd.vectorDB.FindSimilar(ctx,

    story.Embedding,

    dd.thresholds.SemanticMedium,

    10,

)

if err != nil {

    return nil, fmt.Errorf("vector similarity search: %w", err)

}



for _, match := range similarDocs {

    if match.Similarity >= dd.thresholds.SemanticHigh {

        result.IsDuplicate = true

        result.DuplicateType = DuplicateTypeSemantic

        result.MatchedStoryID = &match.StoryID

        result.SimilarityScore = match.Similarity

        result.RecommendedAction = "MERGE"

        return result, nil

    }



    if match.Similarity >= dd.thresholds.SemanticMedium {

        // Check entity overlap for confirmation

        entityOverlap := await dd.calculateEntityOverlap(ctx, story.StoryID, match.StoryID)

        if entityOverlap >= dd.thresholds.EntityOverlapHigh {

                result.IsDuplicate = true

                result.DuplicateType = DuplicateTypeEntityBased

                result.MatchedStoryID = &match.StoryID

                result.SimilarityScore = match.Similarity

                result.RecommendedAction = "REVIEW"

                return result, nil

            }

        }

    }



    // Tier 4: Cross-lingual matching (for stories in different languages)

    if story.Language != "en" {

        translatedMatch := await dd.checkCrossLingual(ctx, story)

        if translatedMatch != nil {

            result.IsDuplicate = true

            result.DuplicateType = DuplicateTypeCrossLingual

            result.MatchedStoryID = &translatedMatch.StoryID

            result.SimilarityScore = translatedMatch.Similarity

            result.RecommendedAction = "REVIEW"

            return result, nil

        }

    }



    return result, nil

}

// calculateEntityOverlap calculates Jaccard similarity of entities between two stories

func (dd *DuplicateDetector) calculateEntityOverlap(

  ctx context.Context,

  storyID1 uuid.UUID,

  storyID2 uuid.UUID,

) (float64, error) {



  session := dd.neo4jClient.NewSession(ctx, neo4j.SessionConfig{})

  defer session.Close(ctx)



  result, err := session.Run(ctx, `

       MATCH (s1:Story {story_id: $id1})-[:INVOLVES_ENTITY]->(e:Entity)

       WITH collect(DISTINCT e.canonical_name) as entities1

       MATCH (s2:Story {story_id: $id2})-[:INVOLVES_ENTITY]->(e:Entity)

       WITH entities1, collect(DISTINCT e.canonical_name) as entities2

       RETURN

         size(entities1) as count1,

         size(entities2) as count2,

         size([e IN entities1 WHERE e IN entities2]) as overlap

  `, map[string]interface{}{

       "id1": storyID1.String(),

       "id2": storyID2.String(),

  })



  if err != nil || !result.Next() {

       return 0, err

      }



      record := result.Record()

      count1 := float64(record.Values[0].(int64))

      count2 := float64(record.Values[1].(int64))

      overlap := float64(record.Values[2].(int64))



      if count1+count2-overlap == 0 {

          return 0, nil

      }



      // Jaccard similarity

      return overlap / (count1 + count2 - overlap), nil

}

// hybridSearch combines vector similarity with graph relevance

func (se *SearchEngine) hybridSearch(

    ctx context.Context,

    request *SearchRequest,

) (*SearchResult, error) {



    result := &SearchResult{SearchType: SearchTypeHybrid}



    // 1. Generate query embedding

    queryEmbedding, err := se.embeddingModel.Embed(ctx, request.Query)

    if err != nil {

        return nil, fmt.Errorf("generate query embedding: %w", err)

    }



    // 2. Vector search for candidate stories

    candidates, err := se.vectorDB.FindSimilar(ctx, queryEmbedding, 0.5, request.Limit*3)

    if err != nil {

        return nil, fmt.Errorf("vector search: %w", err)

}



// 3. Graph-enhanced reranking using Neo4j

storyIDs := make([]string, len(candidates))

for i, c := range candidates {

    storyIDs[i] = c.StoryID.String()

}



session := se.neo4jClient.NewSession(ctx, neo4j.SessionConfig{})

defer session.Close(ctx)



graphResult, err := session.Run(ctx, `

    UNWIND $storyIds as sid

    MATCH (s:Story {story_id: sid})

    WHERE s.tenant_id = $tenantId

    OPTIONAL MATCH (s)-[:BELONGS_TO_TOPIC]->(t:Topic)

    OPTIONAL MATCH (s)-[:INVOLVES_ENTITY]->(e:Entity)

    OPTIONAL MATCH (s)-[:SOURCED_FROM]->(src:Source)

    WITH s,

       count(DISTINCT t) as topic_count,

       count(DISTINCT e) as entity_count,

       collect(DISTINCT src.name)[..5] as source_names,

       // Graph relevance: more connections = more established story

       (topic_count * 0.3 + entity_count * 0.2 +

       size(source_names) * 0.3 + s.source_count * 0.2) as graph_score

    RETURN s.story_id as story_id,

         s.headline as headline,

         s.summary as summary,

         graph_score

     ORDER BY graph_score DESC

     LIMIT $limit

`, map[string]interface{}{

     "storyIds": storyIDs,

     "tenantId": request.Filters.TenantID,

     "limit": request.Limit,

})



if err != nil {

     return nil, fmt.Errorf("graph reranking: %w", err)

}



// 4. Combine vector and graph scores

for graphResult.Next() {

     record := graphResult.Record()



     // Find corresponding vector score

     vectorScore := 0.0

     storyID := record.Values[0].(string)

     for _, c := range candidates {

       if c.StoryID.String() == storyID {

         vectorScore = c.Similarity

         break

               }

          }



          graphScore := record.Values[3].(float64)



          // Hybrid score: 60% vector, 40% graph

          hybridScore := vectorScore*0.6 + graphScore*0.4



          result.Stories = append(result.Stories, StoryHit{

               StoryID: uuid.MustParse(storyID),

               Headline: record.Values[1].(string),

               Summary: record.Values[2].(string),

               Score:   hybridScore,

               MatchType: "HYBRID",

          })

      }



      return result, nil

}

  }

  memory.RelatedStories = relatedStories



  // 3. Extract key entities

  entities, err := sm.extractKeyEntities(ctx, session, storyID,
sm.memoryConfig.MaxEntitiesPerContext)

    if err != nil {

        return nil, fmt.Errorf("extract entities: %w", err)

    }

    memory.KeyEntities = entities



    // 4. Load recent timeline events

    timeline, err := sm.loadTimeline(ctx, session, storyID, 20)

    if err != nil {

        return nil, fmt.Errorf("load timeline: %w", err)

    }

    memory.RecentEvents = timeline



    // 5. Build knowledge graph context (compressed)

    kgContext, err := sm.buildGraphContext(ctx, session, storyID, entities)

    if err == nil {

        memory.KnowledgeGraph = kgContext

    }



    return memory, nil

}



// AssembleRAGContext builds retrieval-augmented generation context

func (sm *StoryMemory) AssembleRAGContext(

    ctx context.Context,

  query string,

  storyID *uuid.UUID,

  maxTokens int,

) (*RAGContext, error) {



  rag := &RAGContext{

      Query:        query,

      AssembledAt: time.Now(),

  }



  // 1. Generate query embedding

  queryEmbedding, err := sm.embeddingModel.Embed(ctx, query)

  if err != nil {

      return nil, fmt.Errorf("generate query embedding: %w", err)

  }



  // 2. Vector search for relevant stories

  filters := map[string]interface{}{}

  if storyID != nil {

      // If story-specific, boost that story's entities

      filters["related_to_story"] = storyID.String()

  }



  relevantStories, err := sm.vectorDB.FindSimilar(ctx, queryEmbedding, 0.6, 20)

  if err != nil {

      return nil, fmt.Errorf("vector search: %w", err)

}



// 3. Load full story details

for _, match := range relevantStories {

    story, err := sm.loadStorySummary(ctx, nil, match.StoryID)

    if err != nil {

         continue

    }

    story.Relevance = match.Similarity

    rag.RetrievedStories = append(rag.RetrievedStories, *story)

}



// 4. Extract relevant entities

entityEmbeddings, _ := sm.vectorDB.FindSimilarEntities(ctx, queryEmbedding, 0.5, 10)

for _, entity := range entityEmbeddings {

    rag.RelevantEntities = append(rag.RelevantEntities, EntitySummary{

         EntityID:     entity.EntityID,

         CanonicalName: entity.CanonicalName,

         EntityType:    entity.EntityType,

         Relevance:     entity.Similarity,

    })

}



// 5. Assemble context text (token-budgeted)

rag.ContextText = sm.assembleContextText(rag, maxTokens)

rag.TokenCount = sm.estimateTokens(rag.ContextText)

    return rag, nil

}



// assembleContextText builds a token-budgeted context string for LLM input

func (sm *StoryMemory) assembleContextText(rag *RAGContext, maxTokens int) string {

    var parts []string

    tokenBudget := maxTokens



    // Add retrieved stories (most relevant first)

    parts = append(parts, "RELEVANT STORIES:")

    for _, story := range rag.RetrievedStories {

        text := fmt.Sprintf("- [%s] %s: %s",

            story.State, story.Headline, truncateText(story.Summary, 200))



        tokenEstimate := sm.estimateTokens(text)

        if tokenBudget-tokenEstimate < 500 {

            break // Reserve 500 tokens for entities and instructions

        }



        parts = append(parts, text)

        tokenBudget -= tokenEstimate

    }



    // Add relevant entities

    parts = append(parts, "\nKEY ENTITIES:")

      for _, entity := range rag.RelevantEntities {

          text := fmt.Sprintf("- %s (%s)", entity.CanonicalName, entity.EntityType)

          parts = append(parts, text)

      }



      return strings.Join(parts, "\n")

}

PART XVI — ARCHITECTURE DECISION RECORDS



```markdown

## ADR-STG-001: Neo4j as Primary Story Graph Database

**Decision:** Neo4j Enterprise 5.x with causal clustering

**Rationale:** Purpose-built graph engine, 10-100x better traversal performance than RDBMS

**Alternatives:** PostgreSQL recursive CTEs, Amazon Neptune, ArangoDB

**Trade-offs:** Additional operational complexity, but essential for graph workloads



## ADR-STG-002: Event-Sourced Story Versioning

**Decision:** All story mutations as immutable events

**Rationale:** Complete audit trail, time-travel queries, conflict resolution

**Alternatives:** Traditional CRUD with version columns, Git-like branching

**Trade-offs:** Storage overhead for events, but essential for editorial integrity



## ADR-STG-003: Hybrid pgvector + Neo4j Architecture

**Decision:** pgvector for embeddings, Neo4j for graph, combined via hybrid search

**Rationale:** Each database optimized for its domain

**Alternatives:** Neo4j-only, dedicated vector DB

**Trade-offs:** Two query systems, but each optimal for its workload



## ADR-STG-004: CQRS for Story Read/Write

**Decision:** Separate command and query models

**Rationale:** Optimize reads and writes independently

**Alternatives:** Single model

**Trade-offs:** Eventual consistency, acceptable for story content



## ADR-STG-005: Entity Resolution with Wikidata Integration

**Decision:** Multi-strategy entity resolution with Wikidata as authority

**Rationale:** Combines graph lookup, Wikidata API, and embedding similarity

**Alternatives:** Graph-only resolution

**Trade-offs:** External API dependency, but significantly better entity linking

```
