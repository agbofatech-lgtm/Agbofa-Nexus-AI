ARCHITECTURE DECISION RECORDS (ADR)



ADR-DIST-001: Connector Plugin Architecture



Decision: Implement platform connectors as independent, hot-swappable plugins behind a
unified interface, not as monolithic integrations.

Rationale: Platforms change APIs frequently, new platforms emerge, and different tenants may
need different platform mixes. Plugin architecture enables independent deployment, testing,
and scaling of each connector.

Alternatives Considered: Monolithic integration layer (rejected — not scalable); third-party
social media management API (rejected — insufficient control, latency, and cost at scale).



ADR-DIST-002: Event-Sourced Publication State



Decision: Use event sourcing for all publication state changes, with Kafka as the event store and
PostgreSQL for materialized views.

Rationale: Publication is inherently event-driven. Event sourcing provides complete audit trail,
enables replay for recovery, and supports real-time monitoring.

Alternatives Considered: Traditional CRUD with state in PostgreSQL (rejected — insufficient for
complex distributed publication tracking).



ADR-DIST-003: Priority-Based Publication Queues



Decision: Implement four priority queues (CRITICAL, HIGH, MEDIUM, LOW) with preemptive
scheduling for breaking news.

Rationale: Breaking news and corrections must publish immediately; scheduled content can
wait. Priority queuing ensures critical content never waits behind bulk scheduled publications.

Consequences: More complex queue management but essential for news platform
requirements.



ADR-DIST-004: Idempotent Publication with Content Hashing



Decision: Every publication request carries a content hash; platforms detect duplicate
submissions via hash comparison.

Rationale: Network failures and retries can cause duplicate publications. Content hashing
enables safe retry without duplicate posts.

Consequences: Additional hash computation but eliminates duplicate publication risk.

2.5 Orchestration Logic



```go

func (po *PublicationOrchestrator) SubmitJob(

      ctx context.Context,

      request *SubmitPublicationJobRequest,

) (*PublicationJob, error) {



      // 1. Validate content package exists and is approved

      contentPackage, err := po.getApprovedContent(ctx, request.ContentPackageID)

      if err != nil {

        return nil, fmt.Errorf("content retrieval: %w", err)

}



// 2. Idempotency check

if request.IdempotencyKey != "" {

    existing, _ := po.stateManager.FindByKey(ctx, request.IdempotencyKey)

    if existing != nil {

        return existing, nil

    }

}



// 3. Create publication job

job := &PublicationJob{

    JobID:         uuid.NewV7().String(),

    ContentPackageID: request.ContentPackageID,

    StoryID:        contentPackage.StoryID,

    JobType:         JobTypeInitial,

    Priority:      request.Priority,

    TargetPlatforms: request.Targets,

    ContentPackage: contentPackage,

    MaxRetries:        3,

    CreatedAt:        time.Now(),

    UpdatedAt:         time.Now(),

}



// 4. Determine timing

if request.Schedule != nil {

    switch {

    case request.Schedule.Immediate != nil:

        job.Status = StatusQueued

        job.ScheduledFor = nil



    case request.Schedule.Scheduled != nil:

        scheduledTime, _ := time.Parse(time.RFC3339, request.Schedule.Scheduled.PublishAt)

        job.Status = StatusScheduled

        job.ScheduledFor = &scheduledTime



    case request.Schedule.Embargo != nil:

        embargoTime, _ := time.Parse(time.RFC3339, request.Schedule.Embargo.EmbargoUntil)

        job.Status = StatusScheduled

        job.EmbargoUntil = &embargoTime

        job.ScheduledFor = &embargoTime

    }

} else {

    job.Status = StatusQueued

}



// 5. Save job

if err := po.stateManager.SaveJob(ctx, job); err != nil {

    return nil, fmt.Errorf("save job: %w", err)

}



// 6. Publish event

     po.eventBus.Publish(ctx, "distribution.job.created", job)



     // 7. Route to appropriate queue

     if job.Status == StatusQueued {

         if job.Priority == PriorityCritical {

             // Immediate processing for critical content

             go po.processJob(context.Background(), job)

         } else {

             po.scheduler.Enqueue(ctx, job)

         }

     } else {

         po.scheduler.Schedule(ctx, job)

     }



     return job, nil

}



func (po *PublicationOrchestrator) processJob(

     ctx context.Context,

     job *PublicationJob,

){



     // Transition to adapting

     job.Status = StatusAdapting

     po.stateManager.UpdateJob(ctx, job)

// Adapt content for each target platform

adaptedContent, err := po.adapterEngine.AdaptForPlatforms(

    ctx, job.ContentPackage, job.TargetPlatforms,

)

if err != nil {

    job.Status = StatusFailed

    po.stateManager.UpdateJob(ctx, job)

    return

}

job.AdaptedContent = adaptedContent



// Transition to publishing

job.Status = StatusPublishing

po.stateManager.UpdateJob(ctx, job)



// Publish to each platform in parallel

var wg sync.WaitGroup

results := make(chan PlatformResult, len(job.TargetPlatforms))



for _, target := range job.TargetPlatforms {

    wg.Add(1)

    go func(t PlatformTarget) {

      defer wg.Done()

      result := po.connectorManager.Publish(ctx, t.Platform, adaptedContent[t.Platform])

      results <- result

    }(target)

}



wg.Wait()

close(results)



// Process results

successCount := 0

failedPlatforms := []string{}



for result := range results {

    if result.Success {

        successCount++

    } else {

        failedPlatforms = append(failedPlatforms, result.Platform)

    }

}



// Determine final status

if successCount == len(job.TargetPlatforms) {

    job.Status = StatusPublished

    job.CompletedAt = timePtr(time.Now())

} else if successCount > 0 {

    job.Status = StatusPartialSuccess

    // Schedule retries for failed platforms

    po.scheduleRetries(ctx, job, failedPlatforms)

} else {

          if job.RetryCount < job.MaxRetries {

              job.Status = StatusRetrying

              job.RetryCount++

              po.scheduleRetry(ctx, job)

          } else {

              job.Status = StatusFailed

          }

      }



      po.stateManager.UpdateJob(ctx, job)

      po.eventBus.Publish(ctx, "distribution.job.completed", job)

}
```

```go
// Twitter/X Connector

type TwitterConnector struct {

    client     *twitter.Client

    rateLimiter *RateLimiter

    config     ConnectorConfig

}



func (tc *TwitterConnector) Publish(

    ctx context.Context,

    content *PlatformContent,

) (*PublishResult, error) {



    // Check rate limits

    if err := tc.rateLimiter.Wait(ctx); err != nil {

        return nil, fmt.Errorf("rate limit: %w", err)

    }



    // Build tweet

    tweet := &twitter.Tweet{

        Text: content.Text,

    }



    // Handle threading for longer content

    if len(content.Text) > 280 {

        tweet.Thread = tc.splitIntoThread(content.Text)

    }



    // Upload media first if present

    if len(content.MediaAttachments) > 0 {

        mediaIDs, err := tc.uploadMediaBatch(ctx, content.MediaAttachments)

        if err != nil {

             return nil, fmt.Errorf("media upload: %w", err)

        }

        tweet.MediaIDs = mediaIDs

    }



    // Publish tweet

    publishedTweet, err := tc.client.Tweets.Create(ctx, tweet)

    if err != nil {

        return tc.handleError(err)

    }



    return &PublishResult{

        Success:          true,

        PlatformPostID: publishedTweet.ID,

        PlatformURL: fmt.Sprintf("https://x.com/i/status/%s", publishedTweet.ID),

        PublishedAt: time.Now(),

    }, nil

}



// Facebook Connector

type FacebookConnector struct {

    client       *facebook.Client

    rateLimiter *RateLimiter

    config     ConnectorConfig

}



func (fc *FacebookConnector) Publish(

    ctx context.Context,

    content *PlatformContent,

) (*PublishResult, error) {



    if err := fc.rateLimiter.Wait(ctx); err != nil {

        return nil, fmt.Errorf("rate limit: %w", err)

    }



    // Determine post type

    postType := fc.determinePostType(content)



    switch postType {

    case "link_post":

        return fc.publishLinkPost(ctx, content)

    case "photo_post":

        return fc.publishPhotoPost(ctx, content)

    case "video_post":

        return fc.publishVideoPost(ctx, content)

    default:

        return fc.publishTextPost(ctx, content)

    }

}

type YouTubeConnector struct {

    rateLimiter *RateLimiter

func (yc *YouTubeConnector) Publish(

    ctx context.Context,

    content *PlatformContent,

) (*PublishResult, error) {



    if err := yc.rateLimiter.Wait(ctx); err != nil {

        return nil, fmt.Errorf("rate limit: %w", err)

    }



    // YouTube publishing requires video upload first

    video := &youtube.Video{

        Snippet: &youtube.VideoSnippet{

             Title:   content.Title,

             Description: content.Description,

             Tags:    content.Tags,

             CategoryId: content.CategoryID,

        },

        Status: &youtube.VideoStatus{

             PrivacyStatus: content.Privacy,

        },

    }



    // Upload video file

    call := yc.client.Videos.Insert([]string{"snippet", "status"}, video)

    call.Media(content.VideoFile)



    uploadedVideo, err := call.Do()

    if err != nil {

        return yc.handleError(err)

    }



    // Upload thumbnail if provided

    if content.Thumbnail != nil {

        yc.client.Thumbnails.Set(uploadedVideo.Id, content.Thumbnail).Do()

    }



    return &PublishResult{

        Success:       true,

        PlatformPostID: uploadedVideo.Id,

        PlatformURL: fmt.Sprintf("https://youtube.com/watch?v=%s", uploadedVideo.Id),

        PublishedAt: time.Now(),

    }, nil

}
```

```go
            Error: fmt.Errorf("no connector registered for platform: %s", platform),

        }

    }

    return PlatformResult{

        Success: false,

        Error: fmt.Errorf("connector unhealthy: %s", health.Message),

// Publish with retry

if err != nil {

    return PlatformResult{

    }

return PlatformResult{
```

```go
type QueueManager struct {

    queues map[PublicationPriority]*PriorityQueue

    redis *redis.Client

}



type PriorityQueue struct {

    Name       string

    Priority PublicationPriority

    Jobs     chan *PublicationJob

}



func (qm *QueueManager) Enqueue(ctx context.Context, job *PublicationJob) error {

    queue := qm.queues[job.Priority]



    select {

    case queue.Jobs <- job:

        return nil

    case <-ctx.Done():

        return ctx.Err()

    default:

        // Queue full - store in Redis as overflow

        return qm.enqueueToRedis(ctx, job)

    }

}



func (qm *QueueManager) EnqueueAt(

    ctx context.Context,

    job *PublicationJob,

    publishTime time.Time,

) error {



    delay := time.Until(publishTime)

    if delay <= 0 {

        // Due now - enqueue immediately

        return qm.Enqueue(ctx, job)

    }



    // Store in Redis sorted set with score = publish time

    score := float64(publishTime.Unix())



    data, _ := json.Marshal(job)

    return qm.redis.ZAdd(ctx, "distribution:scheduled_jobs", &redis.Z{

        Score: score,

        Member: data,

    }).Err()

}



func (qm *QueueManager) ProcessScheduledJobs(ctx context.Context) {

    ticker := time.NewTicker(1 * time.Second)

    defer ticker.Stop()



    for {

        select {

    case <-ticker.C:

      now := float64(time.Now().Unix())



      // Get all jobs scheduled for now or earlier

      jobs, err := qm.redis.ZRangeByScore(ctx, "distribution:scheduled_jobs",
&redis.ZRangeBy{

          Min: "0",

          Max: fmt.Sprintf("%f", now),

      }).Result()



      if err != nil {

          continue

      }



      for _, data := range jobs {

          var job PublicationJob

          json.Unmarshal([]byte(data), &job)



          // Enqueue for processing

          qm.Enqueue(ctx, &job)



          // Remove from scheduled set

          qm.redis.ZRem(ctx, "distribution:scheduled_jobs", data)

      }



    case <-ctx.Done():

              return

          }

      }

}
```

```go
func (se *SyncEngine) SynchronizeStory(

    ctx context.Context,

    storyID string,

    newContent *ContentPackage,

) (*SyncOperation, error) {



    // 1. Get all published versions of this story

    publishedVersions, err := se.stateManager.GetPublishedVersions(ctx, storyID)

    if err != nil {

        return nil, fmt.Errorf("get published versions: %w", err)

    }



    // 2. Calculate diff between current published and new content

    currentContent := publishedVersions.GetLatestContent()

changes := se.diffCalculator.CalculateDiff(currentContent, newContent)



if len(changes) == 0 {

    return nil, nil // No changes needed

}



// 3. Determine sync operation type

opType := se.determineSyncType(changes)



// 4. Create sync operation

operation := &SyncOperation{

    OperationID:      uuid.NewV7().String(),

    StoryID:       storyID,

    OperationType:     opType,

    AffectedPlatforms: publishedVersions.GetPlatforms(),

    Changes:        changes,

    Status:        SyncStatusInProgress,

    CreatedAt:       time.Now(),

}



// 5. Execute sync for each platform

var wg sync.WaitGroup

results := make(chan PlatformSyncResult, len(operation.AffectedPlatforms))



for _, platform := range operation.AffectedPlatforms {

    wg.Add(1)

      go func(p string) {

          defer wg.Done()

      result := se.syncPlatform(ctx, p, publishedVersions.GetPlatformPostID(p), newContent,
changes)

          results <- result

      }(platform)

  }



  wg.Wait()

  close(results)



  // 6. Process results

  allSuccess := true

  for result := range results {

      if !result.Success {

          allSuccess = false

          log.Error().Str("platform", result.Platform).Err(result.Error).Msg("Sync failed")

      }

  }



  if allSuccess {

      operation.Status = SyncStatusCompleted

  } else {

      operation.Status = SyncStatusPartial

  }

      operation.CompletedAt = timePtr(time.Now())



      // 7. Save sync operation

      se.stateManager.SaveSyncOperation(ctx, operation)



      return operation, nil

}
```

```go
func (ce *CorrectionEngine) IssueCorrection(

    ctx context.Context,

    request *CorrectionRequest,

) (*CorrectionResult, error) {



    result := &CorrectionResult{

        CorrectionID: uuid.NewV7().String(),

        StoryID:    request.StoryID,

        Type:      request.CorrectionType,

        Status:    CorrectionStatusInProgress,

        StartedAt: time.Now(),

    }



    switch request.CorrectionType {

    case CorrectionMinor, CorrectionSubstantive, CorrectionUpdate:

        // Update content with correction notice

        result = ce.processContentCorrection(ctx, request)



    case CorrectionRetraction:

        // Full retraction on all platforms

        result = ce.processRetraction(ctx, request)



    case CorrectionTakedown:

        // Legal takedown - remove from all platforms

        result = ce.processTakedown(ctx, request)

    }



    // Log correction

    ce.auditLogger.LogCorrection(ctx, result)



    // Notify stakeholders

    ce.notificationSvc.NotifyCorrection(ctx, result)



    return result, nil

}



func (ce *CorrectionEngine) processRetraction(

    ctx context.Context,

    request *CorrectionRequest,

) *CorrectionResult {



    // 1. Get all published instances

    published, _ := ce.stateManager.GetPublishedVersions(ctx, request.StoryID)



    // 2. Generate retraction notice

    retractionNotice := ce.generateRetractionNotice(request)



    // 3. Update all platforms

    for _, pub := range published.PlatformVersions {

        switch pub.Platform {

        case "web":

            // Update article with retraction banner and update metadata

            ce.updateWebWithRetraction(ctx, pub, retractionNotice)



        case "twitter", "facebook", "linkedin":

            // Post retraction notice (some platforms don't support editing)

            ce.postRetractionNotice(ctx, pub.Platform, retractionNotice, pub.PlatformPostID)



        case "youtube":

            // Update video description and title

            ce.updateYouTubeWithRetraction(ctx, pub, retractionNotice)

        }

    }



    // 4. Update Story Graph

    ce.syncEngine.UpdateStoryGraphWithRetraction(ctx, request.StoryID)



    return &CorrectionResult{

        CorrectionID: uuid.NewV7().String(),

        StoryID:      request.StoryID,

        Type:         CorrectionRetraction,

        Status:       CorrectionStatusCompleted,

        PlatformsUpdated: len(published.PlatformVersions),

        CompletedAt:      time.Now(),

    }

}

func (ce *CorrectionEngine) generateRetractionNotice(

      request *CorrectionRequest,

) *RetractionNotice {



      severityLabels := map[CorrectionSeverity]string{

          SeverityLow:     "Correction",

          SeverityMedium: "Correction",

          SeverityHigh:    "Significant Correction",

          SeverityCritical: "Retraction",

      }



      return &RetractionNotice{

          Title: fmt.Sprintf("%s: %s", severityLabels[request.Severity], request.StoryHeadline),

          Body: request.Description,

          Date: time.Now(),

          Reason: string(request.CorrectionType),

          EditorNote: request.EditorNote,

      }
```

```go
     DeliveryQueued        DeliveryStatusState = "QUEUED"

     DeliveryPublishing DeliveryStatusState = "PUBLISHING"

     DeliveryPublished DeliveryStatusState = "PUBLISHED"

     DeliveryFailed      DeliveryStatusState = "FAILED"

     DeliveryRetrying DeliveryStatusState = "RETRYING"

     DeliveryCancelled DeliveryStatusState = "CANCELLED"

     DeliveryExpired      DeliveryStatusState = "EXPIRED"

     DeliveryAcknowledged DeliveryStatusState = "ACKNOWLEDGED"

)



func (dm *DeliveryMonitor) TrackDelivery(

     ctx context.Context,

     job *PublicationJob,

){

ticker := time.NewTicker(5 * time.Second)

defer ticker.Stop()



for {

    select {

    case <-ticker.C:

        status := dm.checkDeliveryStatus(ctx, job)

        dm.updateMetrics(status)



        // Check for stalled deliveries

        if dm.isStalled(status) {

            dm.alertManager.TriggerAlert(ctx, AlertStalledDelivery, status)

        }



        // Check if all platforms complete

        if status.OverallStatus == DeliveryPublished ||

            status.OverallStatus == DeliveryFailed {

            dm.finalizeDelivery(ctx, status)

            return

        }



    case <-ctx.Done():

        return

    }

}

}



func (dm *DeliveryMonitor) checkDeliveryStatus(

    ctx context.Context,

    job *PublicationJob,

) *DeliveryStatus {



    status := &DeliveryStatus{

        JobID:       job.JobID,

        StoryID:        job.StoryID,

        StartedAt:       job.CreatedAt,

        RetryCount: job.RetryCount,

    }



    successCount := 0



    for _, platformJob := range job.PlatformJobs {

        platformStatus := PlatformDeliveryStatus{

            Platform:     platformJob.Platform,

            AttemptNumber: platformJob.AttemptCount,

        }



        // Check actual platform status

        if platformJob.PlatformPostID != "" {

       postStatus, err := dm.connectorManager.GetStatus(ctx, platformJob.Platform,
platformJob.PlatformPostID)

        if err == nil {

            platformStatus.PlatformPostID = platformJob.PlatformPostID

            platformStatus.PlatformURL = postStatus.URL

            platformStatus.Status = DeliveryPublished

            successCount++

        } else {

            platformStatus.Status = DeliveryFailed

            platformStatus.ErrorMessage = err.Error()

        }

    } else {

        platformStatus.Status = DeliveryPublishing

    }



    status.PlatformStatuses = append(status.PlatformStatuses, platformStatus)

}



// Determine overall status

totalPlatforms := len(job.TargetPlatforms)

if successCount == totalPlatforms {

    status.OverallStatus = DeliveryPublished

    now := time.Now()

    status.CompletedAt = &now

    status.Duration = now.Sub(status.StartedAt)

} else if successCount > 0 {

    status.OverallStatus = DeliveryPublishing

} else if job.RetryCount >= job.MaxRetries {

          status.OverallStatus = DeliveryFailed

          now := time.Now()

          status.CompletedAt = &now

      } else {

          status.OverallStatus = DeliveryPublishing

      }



      return status

}
```

```go
func (ais *AnalyticsIntegrationService) CollectPostMetrics(

     ctx context.Context,

     publishedJobs []*PublishedJob,

     for _, job := range publishedJobs {

       for _, platformJob := range job.PlatformJobs {

         if platformJob.PlatformPostID == "" {

             continue

         }

            client, exists := ais.platformAnalytics[platformJob.Platform]

            if !exists {

                continue

            }



            // Fetch metrics

            metrics, err := client.GetPostMetrics(ctx, platformJob.PlatformPostID)

            if err != nil {

                log.Error().Err(err).Str("platform", platformJob.Platform).Msg("Metrics collection
failed")

                continue

            }



            metrics.StoryID = job.StoryID



            // Store metrics

            ais.metricsStore.StorePostMetrics(ctx, metrics)



            // Publish metrics event

            ais.eventBus.Publish(ctx, "analytics.post.metrics", metrics)

        }

    }

}



func (ais *AnalyticsIntegrationService) StreamRealtimeMetrics(

     ctx context.Context,

){



     for platform, client := range ais.platformAnalytics {

         go func(p string, c PlatformAnalyticsClient) {

           stream, err := c.StreamRealtimeMetrics(ctx)

           if err != nil {

               return

           }



           for metric := range stream {

               metric.Platform = p

               ais.metricsStore.StoreRealtimeMetric(ctx, metric)

               ais.eventBus.Publish(ctx, "analytics.realtime.metric", metric)

           }

         }(platform, client)

     }

}
```

```markdown

## ADR-DIST-001: Connector Plugin Architecture

**Status:** Accepted

**Decision:** Platform connectors as independent, hot-swappable plugins.

**Rationale:** Platforms change APIs frequently. Plugin architecture enables independent
deployment and scaling.

**Consequences:** Plugin management overhead, but essential for agility.



## ADR-DIST-002: Event-Sourced Publication State

**Status:** Accepted

**Decision:** Event sourcing for all publication state with Kafka as event store.

**Rationale:** Complete audit trail, replay capability, real-time monitoring.

**Consequences:** Additional storage, but essential for compliance and recovery.



## ADR-DIST-003: Priority-Based Publication Queues

**Status:** Accepted

**Decision:** Four priority queues with preemptive scheduling for breaking news.

**Rationale:** Breaking news and corrections must never wait behind bulk content.

**Consequences:** Complex queue management, but essential for news platform.



## ADR-DIST-004: Idempotent Publication

**Status:** Accepted

**Decision:** Content hashing for idempotent publication to prevent duplicates.

**Rationale:** Network failures cause retries; must prevent duplicate posts.

**Consequences:** Hash computation overhead, negligible.



## ADR-DIST-005: Breaking News Separate Path

**Status:** Accepted

**Decision:** Dedicated breaking news delivery path with independent infrastructure.

**Rationale:** Breaking news SLAs (30s) require isolated resources from standard content.

**Consequences:** Infrastructure cost, but essential for news platform credibility.



## ADR-DIST-006: Platform Policy as Code

**Status:** Accepted

**Decision:** Platform policies and formatting rules stored as versioned configuration.

**Rationale:** Platform rules change frequently; configuration updates don't require
deployments.

**Consequences:** Configuration management overhead.



## ADR-DIST-007: Analytics Feedback Loop

**Status:** Accepted

**Decision:** Real-time analytics feedback to AI systems for content optimization.

**Rationale:** Continuous improvement of content performance requires closed-loop
feedback.

**Consequences:** Data pipeline complexity but significant engagement improvements.
```
