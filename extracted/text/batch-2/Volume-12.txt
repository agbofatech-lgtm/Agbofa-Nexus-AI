ARCHITECTURE DECISION RECORDS (ADR)



ADR-ORIG-001: Polyglot Persistence for Content Origination



Decision: Use PostgreSQL+pgvector for source registry, MongoDB for raw ingest documents,
Neo4j for Story Graph.

Rationale: Each store matches access patterns—PostgreSQL for relational source management,
MongoDB for schema-flexible raw content, Neo4j for graph-native story relationships.

Alternatives Considered: Single PostgreSQL for everything (rejected due to graph traversal
performance).



ADR-ORIG-002: LangGraph-Inspired State Machines



Decision: Implement content origination workflows using a Golang-native state machine library
with DAG execution, inspired by LangGraph's node-edge model.

Rationale: Production-grade reliability, type safety, and performance of compiled Golang
combined with the proven state machine patterns from LangGraph.

Alternatives Considered: Temporal.io (overhead), direct Python LangGraph (performance
mismatch for high-throughput pipeline).



ADR-ORIG-003: Dual-Mode Ingestion (Poll + Stream)



Decision: RSS/scheduled sources use configurable polling; News APIs use webhook/streaming;
breaking news sources use persistent connections.

Rationale: Matches source capabilities while maintaining consistent internal event-driven
architecture via Kafka.

```go
// Polling Configuration

type RSSIngestionConfig struct {

      PollInterval time.Duration // Default: 5min, Breaking: 30s

      BatchSize     int          // Max items per poll: 100

      BackoffStrategy BackoffConfig

      Timeout       time.Duration // 30s

}



// Polling Algorithm

func (r *RSSIngestor) Poll(ctx context.Context) error {

      // 1. Check source health status

      if !source.IsHealthy() {

          return ErrSourceUnhealthy

      }



      // 2. Respect rate limiting

      if rateLimiter.IsLimited(source.ID) {

          schedule := calculateNextPollTime(source)

          return scheduleRetry(schedule)

      }



      // 3. Fetch with conditional GET (ETag/Last-Modified)

      resp, err := r.fetchWithConditional(source.URL, source.LastETag)

      if resp.StatusCode == 304 { // Not Modified

          return nil

      }



      // 4. Parse and validate each item

      for _, item := range resp.Items {

          if !r.isAlreadyProcessed(item.GUID) {

              document := r.transformToIngestDocument(item)

              r.publishToKafka(document)

          }

      }



      // 5. Update source metadata

      source.LastETag = resp.ETag

      source.LastPollTime = time.Now()



      return nil

}
```

```go
type SourceHealth struct {

      SourceID        string

      AvailabilityScore float64 // 0-100, calculated from recent polls

      LatencyP99       time.Duration

      SuccessRate      float64 // % of successful fetches

      ErrorRate       float64

      LastSuccessfulFetch time.Time

      ConsecutiveFailures int

      Status        SourceStatus // HEALTHY, DEGRADED, FAILING, DISABLED

}



// Health Scoring Algorithm

func calculateHealth(source SourceHealth) float64 {

      availabilityWeight := 0.4

      successRateWeight := 0.3

      latencyWeight := 0.2

      errorRateWeight := 0.1



      score := (source.AvailabilityScore * availabilityWeight) +

           (source.SuccessRate * successRateWeight) +

           (100 - normalizeLatency(source.LatencyP99)) * latencyWeight +

           ((100 - source.ErrorRate) * errorRateWeight)



      return score

}
```

4.3 Story Clustering Algorithm



```go

// Golang service using pgvector for similarity search

type ClusteringEngine struct {

      vectorStore *pgvector.Store

      graphDB        neo4j.Driver

      similarityThreshold float64

}



func (ce *ClusteringEngine) FindOrCreateCluster(doc ProcessedDocument) (*StoryCluster, error)
{

      // 1. Generate embedding for the document

embedding := doc.Embedding



// 2. Query pgvector for similar existing documents

similarDocs, err := ce.vectorStore.FindSimilar(

    context.Background(),

    embedding,

    ce.similarityThreshold, // Cosine similarity > 0.85

    10, // Top N results

)



if len(similarDocs) == 0 {

    // No similar content - create new cluster

    return ce.createNewCluster(doc)

}



// 3. For each similar document, check graph relationships

for _, similar := range similarDocs {

    existingCluster := ce.getClusterForDocument(similar.ID)



    // 4. Validate temporal proximity (same event should be close in time)

    if ce.isTemporallyProximate(doc.Timestamp, existingCluster.EarliestTimestamp) {

      // 5. Validate entity overlap

      if ce.calculateEntityOverlap(doc.Entities, existingCluster.Entities) > 0.6 {

          // Add to existing cluster

          return ce.addToCluster(existingCluster, doc)

      }

          }

      }



      // No good match found - create new cluster

      return ce.createNewCluster(doc)

}



func (ce *ClusteringEngine) calculateEntityOverlap(entities1, entities2 []Entity) float64 {

      set1 := make(map[string]bool)

      for _, e := range entities1 {

          set1[e.CanonicalID] = true

      }



      overlap := 0

      for _, e := range entities2 {

          if set1[e.CanonicalID] {

              overlap++

          }

      }



      return float64(overlap) / float64(math.Min(float64(len(entities1)), float64(len(entities2))))

}
```

4.5 Breaking News Detection



```go

type BreakingNewsDetector struct {

      velocityTracker *VelocityTracker

      sourceWeights       map[string]float64

    keywordPatterns []BreakingPattern

    mlModel         *tensorflow.SavedModel

}



type BreakingPattern struct {

    Keywords       []string

    SourceTypes     []SourceType

    MinSources      int

    TimeWindow        time.Duration

    UrgencyThreshold float64

}



func (bd *BreakingNewsDetector) EvaluateBreaking(cluster *StoryCluster) BreakingAssessment
{

    assessment := BreakingAssessment{

        IsBreaking: false,

        UrgencyScore: 0,

        Confidence: 0,

    }



    // 1. Velocity Check: How fast is this cluster growing?

    velocity := bd.velocityTracker.CalculateVelocity(cluster.ID)

    if velocity > 10 { // 10+ sources in 5 minutes

        assessment.UrgencyScore += 30

    }

      // 2. Source Authority: Are high-trust sources reporting?

      authorityScore := bd.calculateSourceAuthority(cluster.Sources)

      assessment.UrgencyScore += authorityScore * 0.25



      // 3. Keyword Pattern Match

      patternScore := bd.matchBreakingPatterns(cluster.KeyPhrases)

      assessment.UrgencyScore += patternScore * 0.25



      // 4. Geographic Proximity to Known Hotspots

      if bd.isNearConflictZone(cluster.PrimaryLocation) {

          assessment.UrgencyScore += 15

      }



      // 5. ML Model Evaluation

      mlScore := bd.evaluateMLModel(cluster)

      assessment.UrgencyScore += mlScore * 0.25



      // Thresholds

      if assessment.UrgencyScore >= 75 {

          assessment.IsBreaking = true

          assessment.Confidence = math.Min(assessment.UrgencyScore, 100)

      }



      return assessment

}
```

```go
func (em *EscalationManager) HandleBreakingStory(story *CanonicalStory) error {

    // Level 1: Automated Verification (30 second timeout)

    ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)

    defer cancel()



    verification, err := em.truthEngine.RapidVerify(ctx, story.Claims)

    if err != nil || verification.Confidence < 60 {

        // Level 2: Human Review Required

        return em.escalateToEditor(story, "AUTOMATED_VERIFICATION_FAILED")

    }



    // Level 3: Auto-publish with monitoring

    story.State = StoryStatePublished

    story.PublishedAt = time.Now()



    // Set up continuous monitoring for updates

    go em.setupContinuousMonitoring(story.ID)

      // Notify distribution engine

      em.publishBreakingNewsEvent(story)



      return nil

}
```

```go
type StateMachine struct {

      transitions map[StoryState]map[StoryEvent]StoryState

      validators map[StoryEvent]TransitionValidator

}

func NewStoryStateMachine() *StateMachine {

  sm := &StateMachine{

    transitions: map[StoryState]map[StoryEvent]StoryState{

      StoryStateDiscovered: {

           EventAIDetection: StoryStateCandidate,

           EventTimeout:    StoryStateRejected,

      },

      StoryStateCandidate: {

           EventClusterFound: StoryStateClustered,

           EventNoiseDetected: StoryStateRejected,

      },

      StoryStateClustered: {

           EventEditorReview: StoryStateUnderReview,

           EventAutoAccept: StoryStateAccepted,

      },

      StoryStateUnderReview: {

           EventEditorAccept: StoryStateAccepted,

           EventEditorReject: StoryStateRejected,

           EventBreakingDetected: StoryStateBreaking,

      },

      StoryStateAccepted: {

           EventPublish:   StoryStateActive,

           EventBreakingDetected: StoryStateBreaking,

      },

      StoryStateBreaking: {

                  EventVerifyComplete: StoryStateActive,

                  EventDebunked:     StoryStateRejected,

             },

             StoryStateActive: {

                  EventNewDevelopment: StoryStateDeveloping,

                  EventArchive:    StoryStateArchived,

             },

             StoryStateDeveloping: {

                  EventUpdateMerged: StoryStateActive,

             },

        },

    }

    return sm

}



func (sm *StateMachine) Transition(story *CanonicalStory, event StoryEvent) error {

    validNextStates, exists := sm.transitions[story.State]

    if !exists {

        return ErrInvalidState

    }



    nextState, valid := validNextStates[event]

    if !valid {

        return ErrInvalidTransition

    }

      // Validate transition preconditions

      if validator, hasValidator := sm.validators[event]; hasValidator {

           if err := validator.Validate(story); err != nil {

               return fmt.Errorf("transition validation failed: %w", err)

           }

      }



      // Record version before state change

      story.VersionHistory = append(story.VersionHistory, StoryVersion{

           FromState: story.State,

           ToState: nextState,

           Event:     event,

           Timestamp: time.Now(),

      })



      story.State = nextState

      story.Version++

      story.UpdatedAt = time.Now()



      return nil

}
```

```go

type AgentOrchestrator struct {

    discoveryAgents *AgentPool

    detectionAgents *AgentPool

    classifierAgents *AgentPool

}



type AgentPool struct {

    agents []*AIAgent

    semaphore chan struct{} // Controls concurrency

    maxWorkers int

}



func (ap *AgentPool) DelegateTask(ctx context.Context, task AgentTask) (*AgentResult, error) {

    // Acquire semaphore slot

    select {

    case ap.semaphore <- struct{}{}:

        defer func() { <-ap.semaphore }()

    case <-ctx.Done():

        return nil, ctx.Err()

    }



    // Find available agent

    agent := ap.findAvailableAgent()

    if agent == nil {

        // Queue task and wait

        return ap.queueTask(ctx, task)

    }



    // Execute with timeout and retry

    result, err := ap.executeWithRetry(ctx, agent, task, 3)

    return result, err

}



func (ap *AgentPool) executeWithRetry(

    ctx context.Context,

    agent *AIAgent,

    task AgentTask,

    maxRetries int,

) (*AgentResult, error) {

    var lastErr error



    for attempt := 0; attempt <= maxRetries; attempt++ {

        taskCtx, cancel := context.WithTimeout(ctx, 30*time.Second)

        defer cancel()



        result, err := agent.Execute(taskCtx, task)

        if err == nil {

            return result, nil

        }

          lastErr = err



          // Classify error for retry decision

          if !isRetryable(err) {

              return nil, fmt.Errorf("non-retryable error: %w", err)

          }



          // Exponential backoff

          if attempt < maxRetries {

              backoff := time.Duration(math.Pow(2, float64(attempt))) * time.Second

              time.Sleep(backoff)

          }

      }



      return nil, fmt.Errorf("max retries exceeded: %w", lastErr)

}
```

```go
      result, err := opa.Eval(ctx, query, input)

      if err != nil {

           return err

      }



      if !result.Allowed() {

           return ErrUnauthorized

      }



      return nil

}

```

12.5 AI Coding Agent Implementation Notes



```markdown

## IMPLEMENTATION GUIDELINES FOR AI CODING AGENTS



1. SERVICE SKELETON GENERATION:

  - Use `go mod init github.com/agbofa/origination-service`

  - Implement clean architecture: handlers → services → repositories

  - All interfaces defined in `internal/ports`

  - All business logic in `internal/core`

 - All adapters in `internal/adapters`



2. CODE GENERATION PATTERNS:

 - Generate gRPC from protobuf: `protoc --go_out=. --go-grpc_out=.`

 - Generate OpenAPI from protobuf annotations

 - Use `go:generate` for mock generation with `mockgen`

 - Implement repository pattern with interfaces for testability



3. ERROR HANDLING:

 - Use custom error types with error codes

 - Implement `errors.Is()` for error checking

 - Always wrap errors with context: `fmt.Errorf("operation: %w", err)`

 - Log errors at service boundary only



4. CONCURRENCY PATTERNS:

 - Use `errgroup` for parallel operations

 - Implement circuit breaker with `gobreaker`

 - Use `rate.Limiter` from `golang.org/x/time/rate`

 - Context propagation for cancellation



5. DATABASE PATTERNS:

 - Use connection pooling: `pgxpool`

 - Implement repository interfaces

 - Use `sqlx` for complex queries

 - Always use prepared statements

 - Implement optimistic locking with version columns

6. KAFKA PATTERNS:

  - Use `sarama` for Kafka client

  - Implement idempotent producers

  - Consumer groups for parallel processing

  - Manual offset commit after processing



7. TESTING:

  - Use `testcontainers-go` for integration tests

  - Implement table-driven tests

  - Use `httptest` for HTTP handlers

  - Mock external dependencies with generated mocks



8. OBSERVABILITY:

  - Always create spans for external calls

  - Add metrics for business operations

  - Use structured logging with `zerolog`

  - Implement health check endpoints



9. SECURITY:

  - Never log credentials or PII

  - Validate all inputs at boundaries

  - Use constant-time comparisons for secrets

  - Implement rate limiting on all public endpoints

  - Rotate credentials from Vault
```
