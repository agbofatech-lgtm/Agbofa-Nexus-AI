PART I — TRUTH ENGINE ARCHITECTURE



1.1 Purpose, Goals & Core Principles



Purpose: The Truth Engine is the epistemic gatekeeper of Agbofa Nexus AI. It evaluates the
veracity of every claim, source, and story before it enters the editorial pipeline, ensuring only
trustworthy information reaches audiences.



Core Goals:



Goal KPI Target

Prevent False Publication False stories published <0.01%

Maximize Recall True stories correctly identified 99.5%

Source Accountability Sources with complete provenance 100%

Verification Speed (Standard) Time from claim to verification <30s

Verification Speed (Breaking) Time from claim to verification <5s

Audit Completeness Decisions with full audit trail 100%

Human Escalation Accuracy Appropriate human review triggers 98% precision



Core Principles:



1. Verifiability Over Velocity: Never sacrifice accuracy for speed

2. Provenance Immutability: Every claim traces to origin

3. Contestability: Every decision has evidence, every score is explainable

4. Graceful Uncertainty: Unknown ≠ False; the engine quantifies uncertainty

5. Continuous Learning: Feedback loops improve accuracy over time

6. Human-in-the-Loop by Design: Editorial judgment remains sovereign

```go

package sourceverify



import (

    "context"

// SourceTrustScore represents the comprehensive trust evaluation

type SourceTrustScore struct {

    SourceID        string `json:"source_id"`

    OverallScore     float64 `json:"overall_score"`      // 0-100

    AuthorityScore float64 `json:"authority_score"`        // Based on source type/credentials

    AccuracyScore     float64 `json:"accuracy_score"`      // Based on fact-check history

    ConsistencyScore float64 `json:"consistency_score"` // Based on self-consistency

    TimelinessScore float64 `json:"timeliness_score"` // Based on reporting speed

    TransparencyScore float64 `json:"transparency_score"` // Based on methodology disclosure

    CalculatedAt     time.Time `json:"calculated_at"`

    ConfidenceInterval float64 `json:"confidence_interval"` // 95% CI width

    DataPoints      int    `json:"data_points"`       // Number of evaluations

}

// TrustCalculator implements the multi-factor trust model

type TrustCalculator struct {

    factCheckHistory FactCheckRepository

    sourceRegistry SourceRepository

    correctionTracker CorrectionTracker

    weights            TrustWeights

}



type TrustWeights struct {

    Authority float64 // 0.25

    Accuracy          float64 // 0.35

    Consistency float64 // 0.20

    Timeliness float64 // 0.10

    Transparency float64 // 0.10

}



func (tc *TrustCalculator) CalculateSourceTrust(

    ctx context.Context,

    sourceID string,

) (*SourceTrustScore, error) {



    // 1. Retrieve source base data

    source, err := tc.sourceRegistry.GetSource(ctx, sourceID)

    if err != nil {

      return nil, fmt.Errorf("source lookup: %w", err)

}



// 2. Calculate Authority Score based on source type and credentials

authorityScore := tc.calculateAuthorityScore(source)



// 3. Calculate Accuracy Score from fact-check history

accuracyScore, dataPoints := tc.calculateAccuracyScore(ctx, sourceID)



// 4. Calculate Consistency Score

consistencyScore := tc.calculateConsistencyScore(ctx, sourceID)



// 5. Calculate Timeliness Score

timelinessScore := tc.calculateTimelinessScore(source)



// 6. Calculate Transparency Score

transparencyScore := tc.calculateTransparencyScore(source)



// 7. Weighted combination with Bayesian adjustment for low data points

overallScore := tc.weightedCombine(

    authorityScore,

    accuracyScore,

    consistencyScore,

    timelinessScore,

    transparencyScore,

    dataPoints,

)

    // 8. Calculate confidence interval based on data points

    confidenceInterval := tc.calculateConfidenceInterval(dataPoints, overallScore)



    return &SourceTrustScore{

       SourceID:         sourceID,

       OverallScore:      overallScore,

       AuthorityScore:     authorityScore,

       AccuracyScore:      accuracyScore,

       ConsistencyScore: consistencyScore,

       TimelinessScore: timelinessScore,

       TransparencyScore: transparencyScore,

       CalculatedAt:      time.Now(),

       ConfidenceInterval: confidenceInterval,

       DataPoints:       dataPoints,

    }, nil

}



func (tc *TrustCalculator) calculateAccuracyScore(

    ctx context.Context,

    sourceID string,

) (float64, int) {

    // Retrieve last N fact-check results

    results, err := tc.factCheckHistory.GetRecentResults(ctx, sourceID, 100)

    if err != nil || len(results) == 0 {

       // No history: use prior based on source type (Bayesian prior)

    return tc.getPriorAccuracy(sourceID), 0

}



correctCount := 0

totalWeight := 0.0

weightedCorrect := 0.0



for _, result := range results {

    // Recent results weighted more heavily (exponential decay)

    ageInDays := time.Since(result.EvaluatedAt).Hours() / 24

    weight := math.Exp(-ageInDays / 30) // Half-life of 30 days



    if result.VerifiedCorrect {

        weightedCorrect += weight

    }

    totalWeight += weight



    if result.VerifiedCorrect {

        correctCount++

    }

}



rawAccuracy := (weightedCorrect / totalWeight) * 100



// Apply penalty for corrections issued

correctionPenalty := tc.calculateCorrectionPenalty(ctx, sourceID)

    return math.Max(0, rawAccuracy-correctionPenalty), len(results)

}



// Bayesian prior for sources without history

func (tc *TrustCalculator) getPriorAccuracy(sourceID string) float64 {

    // Based on source category

    priors := map[string]float64{

        "OFFICIAL_GOVERNMENT":          85.0,

        "LICENSED_NEWS_WIRE":          90.0,

        "TRUSTED_MEDIA":            75.0,

        "VERIFIED_INDEPENDENT":         65.0,

        "COMMUNITY_NEWS":             45.0,

        "SOCIAL_MEDIA":         25.0,

        "UNVERIFIED":         15.0,

    }



    // Default conservative prior

    return 50.0

}



func (tc *TrustCalculator) weightedCombine(

    authority, accuracy, consistency, timeliness, transparency float64,

    dataPoints int,

) float64 {

    w := tc.weights

      // Raw weighted score

      rawScore := (authority * w.Authority) +

            (accuracy * w.Accuracy) +

            (consistency * w.Consistency) +

            (timeliness * w.Timeliness) +

            (transparency * w.Transparency)



      // Bayesian adjustment: regress toward prior when data is sparse

      // More data → trust the calculated score more

      // Less data → pull toward conservative prior (50)

      bayesianWeight := float64(dataPoints) / (float64(dataPoints) + 10) // 10 is prior strength

      priorScore := 50.0



      adjustedScore := (bayesianWeight * rawScore) + ((1 - bayesianWeight) * priorScore)



      return math.Round(adjustedScore*100) / 100

}
```

```go
package crossvalidate

type CorroborationResult struct {

    ClaimID         string       `json:"claim_id"`

    CorroborationScore float64           `json:"corroboration_score"` // 0-100

  IndependentSources int               `json:"independent_sources"` // Count of independent
confirmations

}



type ConsensusLevel string

const (

  ConsensusStronglyConfirmed ConsensusLevel = "STRONGLY_CONFIRMED" // 5+
independent sources

    ConsensusConfirmed        ConsensusLevel = "CONFIRMED"            // 3-4 independent sources

  ConsensusPartiallyConfirmed ConsensusLevel = "PARTIALLY_CONFIRMED" // 2 independent
sources

    ConsensusUnconfirmed        ConsensusLevel = "UNCONFIRMED"            // 1 source only

    ConsensusDisputed        ConsensusLevel = "DISPUTED"            // Conflicting reports

    ConsensusWidelyDisputed      ConsensusLevel = "WIDELY_DISPUTED"         // Majority disagree

)



type CrossSourceValidator struct {

    sourceGraph       neo4j.Driver

    claimRepository ClaimRepository

    minIndependence float64 // Minimum source independence score to count as separate

}



func (csv *CrossSourceValidator) ValidateClaimCorroboration(

    ctx context.Context,

    claimID string,

) (*CorroborationResult, error) {



    claim, err := csv.claimRepository.GetClaim(ctx, claimID)

    if err != nil {

        return nil, fmt.Errorf("claim retrieval: %w", err)

    }



    // 1. Find all sources reporting this claim or semantically similar claims

    reportingSources, err := csv.findReportingSources(ctx, claim)

    if err != nil {

        return nil, fmt.Errorf("source discovery: %w", err)

    }



    // 2. Calculate source independence graph

    // Sources are "independent" if they don't share ownership, syndication, or citation chains

    independentGroups := csv.clusterIndependentSources(ctx, reportingSources)



    // 3. For each independent group, evaluate their corroboration

  var corroborating, conflicting int

  var sourceValidations []SourceValidation



  for _, group := range independentGroups {

      validation := csv.evaluateSourceGroup(ctx, group, claim)

      sourceValidations = append(sourceValidations, validation)



      if validation.SupportsClaim {

          corroborating++

      } else if validation.ContradictsClaim {

          conflicting++

      }

  }



  // 4. Calculate corroboration score

  corroborationScore := csv.calculateCorroborationScore(

      corroborating,

      conflicting,

      len(independentGroups),

      sourceValidations,

  )



  // 5. Determine consensus level

  consensusLevel := csv.determineConsensus(corroborating, conflicting,
len(independentGroups))

    return &CorroborationResult{

       ClaimID:           claimID,

       CorroborationScore: corroborationScore,

       IndependentSources: corroborating,

       ConflictingSources: conflicting,

       ConsensusLevel:        consensusLevel,

       SourceDetails:       sourceValidations,

    }, nil

}



func (csv *CrossSourceValidator) clusterIndependentSources(

    ctx context.Context,

    sources []Source,

) [][]Source {

    // Use graph analysis to identify truly independent sources

    // Sources that share parent companies, regularly cite each other,

    // or share syndication networks are grouped together



    // Implement union-find on source relationship graph

    uf := NewUnionFind(len(sources))



    for i, sourceA := range sources {

       for j := i+1; j < len(sources); j++ {

             sourceB := sources[j]



             // Check various independence factors

            if csv.areSourcesIndependent(ctx, sourceA, sourceB) {

                continue // Truly independent, don't union

            }



            // Sources are related, union them

            uf.Union(i, j)

        }

    }



    // Group sources by their union-find root

    groups := make(map[int][]Source)

    for i, source := range sources {

        root := uf.Find(i)

        groups[root] = append(groups[root], source)

    }



    // Convert map to slice

    var result [][]Source

    for _, group := range groups {

        result = append(result, group)

    }



    return result

}



func (csv *CrossSourceValidator) areSourcesIndependent(

    ctx context.Context,

    sourceA, sourceB Source,

) bool {

    // Check Neo4j for relationship paths between sources

    query := `

         MATCH path = shortestPath((a:Source {source_id: $idA})-[*..3]-(b:Source {source_id: $idB}))

         RETURN length(path) as distance

    `



    result, err := csv.sourceGraph.Run(ctx, query, map[string]interface{}{

         "idA": sourceA.ID,

         "idB": sourceB.ID,

    })



    if err != nil || result.Err() != nil {

         return true // Assume independent if we can't determine

    }



    // If connected within 3 hops, they're not independent

    return !result.Next()

}



func (csv *CrossSourceValidator) calculateCorroborationScore(

    corroborating, conflicting, totalGroups int,

    validations []SourceValidation,

) float64 {

if totalGroups == 0 {

    return 0

}



// Base score from ratio of corroborating sources

baseScore := (float64(corroborating) / float64(totalGroups)) * 100



// Penalty for conflicts

conflictPenalty := (float64(conflicting) / float64(totalGroups)) * 50



// Weight by source quality

qualityWeight := 0.0

totalWeight := 0.0



for _, v := range validations {

    weight := v.SourceTrustScore / 100

    totalWeight += weight



    if v.SupportsClaim {

        qualityWeight += weight

    } else if v.ContradictsClaim {

        qualityWeight -= weight * 0.5 // Half penalty for dissent

    }

}



qualityAdjustment := 0.0

      if totalWeight > 0 {

          qualityAdjustment = (qualityWeight / totalWeight) * 20 // ±20 points adjustment

      }



      finalScore := baseScore - conflictPenalty + qualityAdjustment

      return math.Max(0, math.Min(100, finalScore))

}
```

```go
func (cv *ClaimVerifier) VerifyClaim(

    ctx context.Context,

    claim *Claim,

) (*ClaimVerificationResult, error) {



    startTime := time.Now()



    // 1. Check if claim is already verified in knowledge graph

    if existing, err := cv.knowledgeGraph.FindVerifiedClaim(ctx, claim); err == nil && existing != nil
{

        return cv.updateExistingVerification(ctx, existing, claim)

    }



    // 2. Parallel verification strategies

    var (

        kgEvidence []Evidence

        apiEvidence []Evidence

        sourceEvidence []Evidence

        kgErr, apiErr, sourceErr error

    )



    var wg sync.WaitGroup

    wg.Add(3)



    // Strategy A: Knowledge Graph lookup

go func() {

  defer wg.Done()

  kgEvidence, kgErr = cv.verifyAgainstKnowledgeGraph(ctx, claim)

}()



// Strategy B: External fact-check APIs

go func() {

  defer wg.Done()

  apiEvidence, apiErr = cv.verifyAgainstExternalAPIs(ctx, claim)

}()



// Strategy C: Source-based verification

go func() {

  defer wg.Done()

  sourceEvidence, sourceErr = cv.verifyAgainstSources(ctx, claim)

}()



wg.Wait()



// 3. Aggregate all evidence

allEvidence := cv.aggregateEvidence(kgEvidence, apiEvidence, sourceEvidence)



// 4. Evaluate evidence and determine verdict

verdict, confidence := cv.evaluateEvidence(ctx, claim, allEvidence)



// 5. Store verification result

    result := &ClaimVerificationResult{

        ClaimID:          claim.ID,

        Verdict:         verdict,

        Confidence:        confidence,

        VerificationMethod: cv.determineMethod(kgErr == nil, apiErr == nil, sourceErr == nil),

func (cv *ClaimVerifier) verifyAgainstKnowledgeGraph(

    ctx context.Context,

    claim *Claim,

) ([]Evidence, error) {

    // Query Neo4j knowledge graph

    // Look for matching entities, relationships, and prior verified claims



    query := `

         MATCH (e:Entity {canonical_name: $subject})

         OPTIONAL MATCH (e)-[r:RELATED_TO]->(related)

         WHERE r.predicate = $predicate

         RETURN e, r, related

    `



    result, err := cv.knowledgeGraph.Query(ctx, query, map[string]interface{}{

         "subject": claim.Subject.CanonicalName,

         "predicate": claim.Predicate,

    })



    if err != nil {

         return nil, err

    }



    return cv.convertGraphResultToEvidence(result), nil

}



func (cv *ClaimVerifier) evaluateEvidence(

    ctx context.Context,

    claim *Claim,

    evidence []Evidence,

) (Verdict, float64) {



    supportingWeight := 0.0

    contradictingWeight := 0.0

totalWeight := 0.0



for _, e := range evidence {

    weight := e.ReliabilityScore * e.RelevanceScore



    if e.SupportsClaim {

        supportingWeight += weight

    } else {

        contradictingWeight += weight

    }

    totalWeight += weight

}



if totalWeight == 0 {

    return VerdictUnverifiable, 0.0

}



supportRatio := supportingWeight / totalWeight



// Confidence based on evidence quality and quantity

evidenceQuantityBonus := math.Min(float64(len(evidence))/10.0, 1.0) * 0.2

confidence := supportRatio + evidenceQuantityBonus

confidence = math.Min(confidence, 1.0)



// Map to verdict

switch {

      case supportRatio >= 0.95:

          return VerdictTrue, confidence

      case supportRatio >= 0.80:

          return VerdictMostlyTrue, confidence

      case supportRatio >= 0.60:

          return VerdictHalfTrue, confidence

      case supportRatio >= 0.40:

          return VerdictMostlyFalse, confidence

      case supportRatio >= 0.20:

          return VerdictFalse, confidence

      default:

          if len(evidence) > 0 {

              return VerdictFalse, confidence

          }

          return VerdictUnverifiable, 0.0

      }

}
```

```go
func (dd *DuplicateDetector) GenerateFingerprint(story *CanonicalStory) *StoryFingerprint {

    for i, e := range story.Entities {

    combined := semanticHash + entityHash + temporalHash + structuralHash

    combinedHash := dd.hashString(combined)

        StoryID:      story.StoryID,

        SemanticHash: semanticHash,

        EntityHash:    entityHash,

        TemporalHash: temporalHash,

        StructuralHash: structuralHash,

        CombinedHash: combinedHash,
```

```go
type StoryMergeWorkflow struct {

func (smw *StoryMergeWorkflow) ExecuteMerge(

      ctx context.Context,

      sourceStory *CanonicalStory,

      duplicateResult *DuplicateResult,

) (*CanonicalStory, error) {

  if !duplicateResult.IsDuplicate {

      return sourceStory, nil

  }



  bestCandidate := duplicateResult.Candidates[0]



  // Get canonical (oldest/most complete) story

  canonicalStory, err := smw.storyGraph.GetStory(ctx, bestCandidate.StoryID)

  if err != nil {

      return nil, fmt.Errorf("get canonical story: %w", err)

  }



  // Decide merge strategy

  mergeStrategy := smw.determineMergeStrategy(sourceStory, canonicalStory, bestCandidate)



  switch mergeStrategy {

  case MergeStrategyUpdate:

      // Update existing canonical story with new information

      updatedStory, err := smw.updateCanonicalStory(ctx, canonicalStory, sourceStory)

      if err != nil {

          return nil, fmt.Errorf("update canonical: %w", err)

      }



      // Create relationship in graph

   smw.storyGraph.CreateMergeRelationship(ctx, canonicalStory.StoryID, sourceStory.StoryID,
"MERGED_INTO")

        return updatedStory, nil



    case MergeStrategyReplace:

        // New story is more authoritative, replace canonical

    smw.storyGraph.CreateMergeRelationship(ctx, sourceStory.StoryID, canonicalStory.StoryID,
"SUPERSEDES")

        return sourceStory, nil



    case MergeStrategyBranch:

        // Significant difference, create as variant

        variantStory := smw.createStoryVariant(ctx, sourceStory, canonicalStory)

        return variantStory, nil



    default:

        return sourceStory, nil

    }

}



type MergeStrategy string

const (

    MergeStrategyUpdate MergeStrategy = "UPDATE"

    MergeStrategyReplace MergeStrategy = "REPLACE"

    MergeStrategyBranch MergeStrategy = "BRANCH"

)

func (smw *StoryMergeWorkflow) determineMergeStrategy(

      newStory, existingStory *CanonicalStory,

      candidate DuplicateCandidate,

) MergeStrategy {

      // If new story adds significant new information

      if smw.hasSignificantNewInfo(newStory, existingStory) {

          // Check if sources are more authoritative

          newSourceScore := smw.averageSourceScore(newStory)

          existingSourceScore := smw.averageSourceScore(existingStory)



          if newSourceScore > existingSourceScore * 1.5 {

              return MergeStrategyReplace

          }



          return MergeStrategyUpdate

      }



      // If stories are significantly different despite being duplicates

      if smw.calculateDivergence(newStory, existingStory) > 0.3 {

          return MergeStrategyBranch

      }



      return MergeStrategyUpdate

}
```

```go
type StoryVersion struct {

type Change struct {

    Field string       `json:"field"` // e.g., "headline", "entities[2].name"

    OldValue interface{} `json:"old_value"`

    NewValue interface{} `json:"new_value"`

    Op    string    `json:"op"`      // "replace", "add", "remove"

}

func (svm *StoryVersionManager) CreateNewVersion(

  ctx context.Context,

  storyID string,

  changes []Change,

  reason string,

  triggerEvent string,

  createdBy string,

) (*StoryVersion, error) {



  // 1. Get current story

  currentStory, err := svm.getCurrentStory(ctx, storyID)

  if err != nil {

      return nil, fmt.Errorf("get current story: %w", err)

  }



  // 2. Apply changes to create new version

  newStory := svm.applyChanges(currentStory, changes)

  newStory.Version = currentStory.Version + 1

  newStory.UpdatedAt = time.Now()



  // 3. Create version record

  version := &StoryVersion{

      VersionID: uuid.NewV7().String(),

      StoryID:      storyID,

      Version:      newStory.Version,

      Snapshot:      *newStory,

    Changes:       changes,

    ChangeReason: reason,

    TriggerEvent: triggerEvent,

    CreatedBy: createdBy,

    CreatedAt: time.Now(),

}



// 4. Store version in MongoDB (full snapshot)

if _, err := svm.mongoDB.InsertOne(ctx, version); err != nil {

    return nil, fmt.Errorf("store version: %w", err)

}



// 5. Update Neo4j with new version link

_, err = svm.graphDB.Run(ctx, `

    MATCH (s:Story {story_id: $storyID})

    SET s.version = $newVersion, s.updated_at = datetime()

    CREATE (v:StoryVersion {

         version_id: $versionID,

         version: $newVersion,

         reason: $reason,

         created_at: datetime()

    })

    CREATE (s)-[:HAS_VERSION]->(v)

`, map[string]interface{}{

    "storyID": storyID,

    "newVersion": newStory.Version,

         "versionID": version.VersionID,

         "reason":    reason,

    })



    if err != nil {

         return nil, fmt.Errorf("update graph version: %w", err)

    }



    // 6. Publish version event

    svm.eventBus.Publish(ctx, "truth_engine.story.versioned", StoryVersionedEvent{

         StoryID: storyID,

         Version: newStory.Version,

         VersionID: version.VersionID,

         Changes: changes,

         Timestamp: time.Now(),

    })



    return version, nil

}



func (svm *StoryVersionManager) GetVersionHistory(

    ctx context.Context,

    storyID string,

) ([]StoryVersion, error) {

    // Retrieve all versions from MongoDB, sorted by version desc

    filter := bson.M{"story_id": storyID}

    opts := options.Find().SetSort(bson.D{{"version", -1}})



    cursor, err := svm.mongoDB.Find(ctx, filter, opts)

    if err != nil {

        return nil, err

    }

    defer cursor.Close(ctx)



    var versions []StoryVersion

    if err := cursor.All(ctx, &versions); err != nil {

        return nil, err

    }



    return versions, nil

}



func (svm *StoryVersionManager) RollbackToVersion(

    ctx context.Context,

    storyID string,

    targetVersion int64,

    reason string,

    requestedBy string,

) (*StoryVersion, error) {

    // 1. Get target version snapshot

    filter := bson.M{

        "story_id": storyID,

           "version": targetVersion,

      }



      var targetVersionDoc StoryVersion

      if err := svm.mongoDB.FindOne(ctx, filter).Decode(&targetVersionDoc); err != nil {

           return nil, fmt.Errorf("target version not found: %w", err)

      }



      // 2. Get current version to calculate rollback changes

      currentStory, _ := svm.getCurrentStory(ctx, storyID)



      // 3. Create rollback version

      rollbackChanges := []Change{{

           Field: "__rollback__",

           OldValue: currentStory.Version,

           NewValue: targetVersion,

           Op:    "rollback",

      }}



      return svm.CreateNewVersion(

           ctx, storyID, rollbackChanges, reason,

           "ROLLBACK", requestedBy,

      )

}
```

```go
func (ce *ConfidenceEngine) CalculateStoryConfidence(

    ctx context.Context,

    story *CanonicalStory,

) (*StoryConfidenceScore, error) {



    var (

        sourceScore float64

        claimScore   float64

        crossScore   float64

        evidenceScore float64

        recencyScore float64

        misinfoScore float64

        explanations []ExplanationFactor

    )



    // 1. Source Trust Assessment (weight: 0.25)

    sourceScore, sourceExplanations := ce.evaluateSourceTrust(ctx, story)

    explanations = append(explanations, sourceExplanations...)

// 2. Claim Verification (weight: 0.30)

claimScore, claimExplanations := ce.evaluateClaims(ctx, story)

explanations = append(explanations, claimExplanations...)



// 3. Cross-Source Validation (weight: 0.20)

crossScore, crossExplanations := ce.evaluateCrossSource(ctx, story)

explanations = append(explanations, crossExplanations...)



// 4. Evidence Quality (weight: 0.15)

evidenceScore, evidenceExplanations := ce.evaluateEvidence(ctx, story)

explanations = append(explanations, evidenceExplanations...)



// 5. Recency Assessment (weight: 0.05)

recencyScore = ce.evaluateRecency(story)



// 6. Misinformation Risk (weight: 0.05, negative)

misinfoScore, misinfoExplanations := ce.evaluateMisinfoRisk(ctx, story)

explanations = append(explanations, misinfoExplanations...)



// Weighted combination

cfg := ce.config

overallScore :=

  (sourceScore * cfg.SourceTrustWeight) +

  (claimScore * cfg.ClaimVerificationWeight) +

  (crossScore * cfg.CrossSourceWeight) +

   (evidenceScore * cfg.EvidenceQualityWeight) +

   (recencyScore * cfg.RecencyWeight) -

   (misinfoScore * cfg.MisinfoPenaltyWeight)



// Normalize to 0-100

overallScore = math.Max(0, math.Min(100, overallScore))



// Determine recommended action

action := ce.determineAction(overallScore, story.Priority == PriorityBreaking)



return &StoryConfidenceScore{

   StoryID:         story.StoryID,

   OverallConfidence: overallScore,

   DimensionalScores: DimensionalScores{

         SourceTrustScore:     sourceScore,

         ClaimVerificationScore: claimScore,

         CrossSourceScore:     crossScore,

         EvidenceQualityScore: evidenceScore,

         RecencyScore:        recencyScore,

         MisinfoRiskScore:     misinfoScore,

   },

   VerificationStatus: ce.determineStatus(overallScore),

   RecommendedAction: action,

   CalculatedAt:         time.Now(),

   ExplanationFactors: explanations,

}, nil

}



func (ce *ConfidenceEngine) evaluateSourceTrust(

    ctx context.Context,

    story *CanonicalStory,

) (float64, []ExplanationFactor) {

    if len(story.Sources) == 0 {

        return 0, []ExplanationFactor{{

             Factor:      "Source Trust",

             Impact:      -25,

             Description: "No sources available for evaluation",

        }}

    }



    var totalTrust float64

    var explanations []ExplanationFactor



    for _, sourceRef := range story.Sources {

        trustScore, err := ce.sourceVerifier.GetSourceTrustScore(ctx, sourceRef.SourceID)

        if err != nil {

             totalTrust += 50 // Neutral score for unknown sources

             continue

        }

        totalTrust += trustScore.OverallScore

    }

    avgTrust := totalTrust / float64(len(story.Sources))



    if avgTrust >= 80 {

        explanations = append(explanations, ExplanationFactor{

             Factor:   "Source Trust",

             Impact:    +15,

             Description: fmt.Sprintf("High average source trust (%.1f)", avgTrust),

        })

    } else if avgTrust < 40 {

        explanations = append(explanations, ExplanationFactor{

             Factor:   "Source Trust",

             Impact:    -15,

             Description: fmt.Sprintf("Low average source trust (%.1f)", avgTrust),

        })

    }



    return avgTrust, explanations

}



func (ce *ConfidenceEngine) determineAction(score float64, isBreaking bool) EditorialAction {

    if isBreaking {

        // Lower thresholds for breaking news

        if score >= 70 {

             return ActionAutoPublish

        } else if score >= 50 {

             return ActionHumanReview

        }

        return ActionReject

    }



    if score >= ce.config.AutoPublishThreshold {

        return ActionAutoPublish

    } else if score >= ce.config.HumanReviewThreshold {

        return ActionHumanReview

    }

    return ActionReject

}
```

```go
func (pc *ProvenanceChain) RecordAction(

  actor Actor,

  action AuditAction,

  target AuditTarget,

  beforeState, afterState interface{},

  metadata map[string]interface{},

) (*AuditEntry, error) {

  if err != nil {

      return nil, fmt.Errorf("get last entry: %w", err)

  }



  previousHash := ""

  if lastEntry != nil {

      previousHash = lastEntry.Hash

  }



  // 2. Serialize states

  beforeJSON, _ := json.Marshal(beforeState)

  afterJSON, _ := json.Marshal(afterState)

  metadataJSON, _ := json.Marshal(metadata)



  // 3. Create entry

    entry := &AuditEntry{

        Actor:      actor,

        Action:     action,

        Target:     target,

        AfterState: afterJSON,

        Metadata:     metadataJSON,

    entry.Hash = pc.calculateHash(entry)

        return nil, fmt.Errorf("append to immutable log: %w", err)

    }

    pc.eventStore.Publish(ctx, "truth_engine.audit.entry", entry)



    return entry, nil

}

func (pc *ProvenanceChain) calculateHash(entry *AuditEntry) string {

    // SHA-256 hash of all entry fields including previous hash

    data := fmt.Sprintf("%s|%s|%s|%s|%s|%s|%s|%s",

        entry.EntryID,

        entry.PreviousHash,

        entry.Timestamp.Format(time.RFC3339Nano),

        entry.Actor.ActorID,

        entry.Action,

        entry.Target.TargetID,

        entry.BeforeState,

        entry.AfterState,

    )



    hash := sha256.Sum256([]byte(data))

    return hex.EncodeToString(hash[:])

}



func (pc *ProvenanceChain) VerifyChainIntegrity(

    ctx context.Context,

    targetID string,

) (*IntegrityReport, error) {

    entries, err := pc.getFullChain(ctx, targetID)

    if err != nil {

        return nil, err

    }

report := &IntegrityReport{

    TargetID: targetID,

    TotalEntries: len(entries),

    Verified:    true,

    CheckedAt: time.Now(),

}



var previousHash string



for i, entry := range entries {

    // Verify hash chain

    if entry.PreviousHash != previousHash {

        report.Verified = false

        report.BreakAtEntry = i

        report.ExpectedHash = previousHash

        report.FoundHash = entry.PreviousHash

        break

    }



    // Verify entry hash

    calculatedHash := pc.calculateHash(&entry)

    if calculatedHash != entry.Hash {

        report.Verified = false

        report.BreakAtEntry = i

        report.ExpectedHash = calculatedHash

        report.FoundHash = entry.Hash

            break

        }



        previousHash = entry.Hash

    }



    return report, nil

}
```

7.3 Event Ordering and Processing Guarantees



```go

// Event ordering and idempotency implementation

type EventProcessor struct {

      consumer        kafka.Consumer

      processedIDs *redis.Client // Track processed event IDs

      deadLetterQ kafka.Producer

}



func (ep *EventProcessor) ProcessWithGuarantees(

      ctx context.Context,

      handler EventHandler,

) error {

      for {

        msg, err := ep.consumer.ReadMessage(ctx)

        if err != nil {

              return err

        }



        eventID := ep.extractEventID(msg)



        // 1. Idempotency check

        alreadyProcessed, err := ep.processedIDs.Exists(ctx, eventID).Result()

if err != nil {

    return fmt.Errorf("idempotency check: %w", err)

}

if alreadyProcessed > 0 {

    ep.consumer.CommitMessages(ctx, msg)

    continue

}



// 2. Process event with retry

if err := ep.processWithRetry(ctx, handler, msg); err != nil {

    // 3. Dead letter queue for failed events

    ep.deadLetterQ.Produce(ctx, &kafka.Message{

         Topic: "truth_engine.dlq",

         Key: msg.Key,

         Value: msg.Value,

         Headers: []kafka.Header{

              {Key: "error", Value: []byte(err.Error())},

              {Key: "original_topic", Value: []byte(*msg.TopicPartition.Topic)},

              {Key: "retry_count", Value: []byte("3")},

         },

    })



    // Still commit to move past failed message

    ep.consumer.CommitMessages(ctx, msg)

    continue

}

        // 4. Mark as processed (with TTL)

        ep.processedIDs.Set(ctx, eventID, "processed", 24*time.Hour)



        // 5. Commit offset

        ep.consumer.CommitMessages(ctx, msg)

    }

}



func (ep *EventProcessor) processWithRetry(

    ctx context.Context,

    handler EventHandler,

    msg *kafka.Message,

) error {

    const maxRetries = 3



    for attempt := 0; attempt < maxRetries; attempt++ {

        err := handler.Handle(ctx, msg)

        if err == nil {

            return nil

        }



        if !isRetryable(err) {

            return fmt.Errorf("non-retryable: %w", err)

        }

          // Exponential backoff

          time.Sleep(time.Duration(math.Pow(2, float64(attempt))) * time.Second)

      }



      return fmt.Errorf("max retries exceeded")

}
```

```go
func (sa *SourceAuthenticator) AuthenticateSource(

    ctx context.Context,

    source *Source,

    result := &AuthenticationResult{

      SourceID: source.ID,

      Authenticated: false,

    Checks:    make(map[string]bool),

}



// 1. DNS verification

dnsValid, err := sa.dnsVerifier.Verify(source.URL)

result.Checks["dns"] = dnsValid



// 2. TLS certificate verification

tlsValid, certInfo := sa.tlsVerifier.Verify(source.URL)

result.Checks["tls"] = tlsValid

if certInfo != nil {

    result.CertificateInfo = certInfo

}



// 3. Domain ownership verification

domainValid := sa.domainRegistry.VerifyOwnership(source.URL, source.ClaimedOwner)

result.Checks["domain_ownership"] = domainValid



// 4. Historical consistency check

historicalValid := sa.checkHistoricalConsistency(source)

result.Checks["historical_consistency"] = historicalValid



// 5. Content signing verification (if applicable)

if source.UsesSigning {

    sigValid := sa.verifyContentSignature(source)

    result.Checks["content_signature"] = sigValid

    }



    // Determine authentication result

    criticalChecks := []string{"dns", "tls", "domain_ownership"}

    criticalPassed := true

    for _, check := range criticalChecks {

        if !result.Checks[check] {

            criticalPassed = false

            break

        }

    }



    result.Authenticated = criticalPassed

    result.Confidence = sa.calculateAuthenticationConfidence(result.Checks)



    return result, nil

}



// Data Integrity Validation

type DataIntegrityValidator struct{}



func (div *DataIntegrityValidator) ValidateBeforeProcessing(

    ctx context.Context,

    data *RawContent,

) error {

    // 1. Check content hash matches

    if !div.verifyContentHash(data) {

        return ErrContentHashMismatch

    }



    // 2. Validate against schema

    if err := div.validateSchema(data); err != nil {

        return fmt.Errorf("schema validation: %w", err)

    }



    // 3. Check for injection attempts

    if div.detectInjection(data) {

        return ErrInjectionDetected

    }



    // 4. Validate timestamps (no future dates, reasonable ranges)

    if !div.validateTimestamps(data) {

        return ErrInvalidTimestamps

    }



    // 5. Check for malformed content

    if div.detectMalformedContent(data) {

        return ErrMalformedContent

    }



    return nil

}

// Replay Attack Prevention

type ReplayDetector struct {

    processedHashes *redis.Client

}



func (rd *ReplayDetector) CheckReplay(ctx context.Context, content *Content) error {

    // Generate content hash

    contentHash := sha256Hash(content)



    // Check if already processed

    exists, err := rd.processedHashes.Exists(ctx, contentHash).Result()

    if err != nil {

        return err

    }



    if exists > 0 {

        // Potential replay attack

        return ErrReplayDetected

    }



    // Store hash with TTL

    rd.processedHashes.Set(ctx, contentHash, time.Now().String(), 30*24*time.Hour)



    return nil

}

// Citation Verification

type CitationVerifier struct {

    knowledgeGraph KnowledgeGraphClient

    webArchive       WebArchiveClient

}



func (cv *CitationVerifier) VerifyCitation(

    ctx context.Context,

    citation *Citation,

) (*CitationVerification, error) {



    verification := &CitationVerification{

        CitationID: citation.ID,

        Verified: false,

    }



    // 1. Check if cited source exists

    sourceExists := cv.checkSourceExistence(ctx, citation.SourceURL)

    verification.SourceExists = sourceExists



    // 2. Verify cited content matches

    contentMatch, matchScore := cv.verifyContentMatch(ctx, citation)

    verification.ContentMatch = contentMatch

    verification.MatchScore = matchScore

    // 3. Archive.org lookup for historical citations

    if citation.IsHistorical {

        archiveMatch := cv.webArchive.Verify(ctx, citation)

        verification.ArchiveMatch = archiveMatch

    }



    // 4. Knowledge graph validation

    kgValid := cv.knowledgeGraph.ValidateReference(ctx, citation)

    verification.KnowledgeGraphValid = kgValid



    // Determine if citation is legitimate

    verification.Verified = sourceExists && contentMatch



    // Flag suspicious patterns

    if !sourceExists && contentMatch {

        verification.SuspiciousPattern = "CONTENT_EXISTS_WITHOUT_SOURCE"

    }



    return verification, nil

}



// Audit Bypass Prevention

type AuditEnforcer struct {

    auditLog *ImmutableLog

}

func (ae *AuditEnforcer) EnsureAuditability(action func() error) error {

      // Pre-action audit record

      preEntry := ae.createAuditEntry("ACTION_STARTED")



      // Execute action

      err := action()



      // Post-action audit record (always records, even on error)

      postEntry := ae.createAuditEntry("ACTION_COMPLETED")

      if err != nil {

          postEntry.Error = err.Error()

      }



      // Both entries must be written

      if writeErr := ae.auditLog.AppendBatch([]AuditEntry{preEntry, postEntry}); writeErr != nil {

          // Audit write failure triggers alert and blocks further processing

          ae.triggerAuditFailureAlert(writeErr)

          return fmt.Errorf("audit enforcement: %w", writeErr)

      }



      return err

}
```

```markdown
## ADR-TRUTH-001: Multi-Factor Confidence Scoring Model

**Status:** Accepted

**Date:** 2026-08-07

**Decision:** Implement a weighted multi-factor confidence scoring model with dimensions
for source trust, claim verification, cross-source validation, evidence quality, recency, and
misinformation risk.

**Rationale:** Single-dimension scoring is insufficient for news veracity. Multi-factor approach
allows nuanced evaluation and explainable scores. Weighted combination allows tuning per
story category.

**Consequences:** More complex calculation, requires calibration, but provides better
accuracy and explainability.



## ADR-TRUTH-002: Neo4j as Primary Story Graph Store

**Status:** Accepted

**Date:** 2026-08-07

**Decision:** Use Neo4j Enterprise as the primary Story Graph database, with MongoDB for
version snapshots and PostgreSQL for operational metadata.

**Rationale:** Neo4j's native graph capabilities are essential for provenance chains, entity
relationships, source independence analysis, and complex traversal queries. Polyglot persistence
optimizes each use case.

**Consequences:** Additional operational complexity managing three database types, but
each is optimized for its workload.



## ADR-TRUTH-003: Append-Only Audit Log with Cryptographic Chaining

**Status:** Accepted

**Date:** 2026-08-07

**Decision:** Implement an immutable audit log using SHA-256 cryptographic chaining
(blockchain-like) for all verification and editorial decisions.

**Rationale:** Regulatory compliance, tamper-evidence, and complete traceability require
cryptographic guarantees. Traditional audit logs are insufficient for high-stakes news
verification.

**Consequences:** Higher storage costs, write latency for audit entries, but provides non-
repudiable audit trail.



## ADR-TRUTH-004: Human-in-the-Loop for High-Risk Categories

**Status:** Accepted

**Date:** 2026-08-07

**Decision:** Automatically escalate stories in health, financial, legal, and political categories
for human review unless confidence exceeds 95%.

**Rationale:** These categories have highest potential for real-world harm if inaccurate. AI
confidence alone is insufficient for life-impacting information.

**Consequences:** Increased editorial workload for these categories, but appropriate for risk
mitigation.



## ADR-TRUTH-005: Dual-Path Verification (Standard vs Breaking)

**Status:** Accepted

**Date:** 2026-08-07

**Decision:** Implement separate verification paths: comprehensive multi-source verification
for standard news, accelerated minimal-verification for breaking news with continuous post-
publication monitoring.

**Rationale:** Breaking news requires speed; standard news requires thoroughness. Separate
paths optimize for both requirements without compromising either.

**Consequences:** Additional code complexity maintaining two paths, but necessary for the
news domain.

## ADR-TRUTH-006: External Fact-Check API Integration

**Status:** Accepted

**Date:** 2026-08-07

**Decision:** Integrate with external fact-check APIs (Google Fact Check, ClaimReview) as
supplementary verification sources, not primary truth arbiters.

**Rationale:** External APIs provide valuable corroboration but cannot be sole arbiters of
truth. They supplement, not replace, internal verification.

**Consequences:** Dependency on external services, API costs, but provides broader
verification coverage.



## ADR-TRUTH-007: Evidence-Based Verdict Classification

**Status:** Accepted

**Date:** 2026-08-07

**Decision:** Use a 9-point verdict scale (True, Mostly True, Half True, Mostly False, False,
Unverifiable, Misleading, Out of Context, Unsupported) based on evidence weight.

**Rationale:** Binary true/false is insufficient for nuanced news verification. Multi-point scale
similar to established fact-checking organizations provides appropriate granularity.

**Consequences:** More complex classification logic, but better reflects real-world verification
outcomes.



## ADR-TRUTH-008: Confidence Score Decay for Time-Sensitive Claims

**Status:** Accepted

**Date:** 2026-08-07

**Decision:** Implement confidence score decay for claims where verification evidence
becomes stale. Re-verify claims after configurable expiry periods.

**Rationale:** News accuracy degrades over time as new information emerges. Static
confidence scores become misleading.

**Consequences:** Additional computational cost for periodic re-verification, but maintains
accuracy over time.
```

13.1 Architecture Overview



The Truth Engine is the epistemic core of Agbofa Nexus AI, providing comprehensive, multi-
layered verification of every piece of information before it enters the editorial pipeline. It
combines source authentication, claim verification, cross-source validation, misinformation
detection, and confidence scoring into a single, event-driven verification system.



Key Architectural Highlights:



· Multi-Factor Confidence Scoring: Six-dimensional evaluation providing nuanced truth
assessment

· Immutable Audit Trail: Cryptographically chained, append-only log for complete traceability

· Neo4j-Powered Story Graph: Graph-native storage enabling complex provenance and
relationship queries

· Dual-Path Processing: Optimized paths for both breaking news (speed) and standard news
(thoroughness)

· Human-in-the-Loop Integration: Intelligent escalation based on risk category and confidence
thresholds

· External Fact-Check Integration: Supplementary verification from established fact-checking
organizations
