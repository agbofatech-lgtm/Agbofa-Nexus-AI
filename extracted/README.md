# Extracted Documentation Artifacts

This directory stores derived artifacts generated from immutable source documents.

## Directories

- `ocr-json/` — OCR/layout-preserved JSON for AI processing.
- `markdown/` — structured Markdown for Git, review, and publication.
- `text/` — plain text extraction for search and analysis.
- `images/` — extracted images and diagrams.

Derived files must preserve traceability back to source documents and checksums.
