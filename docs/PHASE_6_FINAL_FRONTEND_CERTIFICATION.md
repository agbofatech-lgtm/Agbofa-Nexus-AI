## Executive experience

### Executive situation

The page presents current operating state, major change, top modeled opportunity, highest simulated risk, decision pressure, strategy direction, and learning signal. Every item retains source ID, provenance, confidence where available, and execution reality.

### KPI authority

The KPI layer derives audience, reach, engagement, conversion, distribution, experiments, strategic progress, and estimated AI cost from canonical sources. Revenue remains `UNAVAILABLE`. No metric is labeled live.

### Priority desk

The page presents the top three existing opportunities, three highest-priority existing decisions, and three existing Phase 4 strategies with links to their canonical detailed experiences.

### Operating state

Workforce, experiment, learning, and economics summaries are projections of their canonical owners. Agent count remains 28. Actual cost, actual revenue, and verified ROI remain unavailable.

### Global command search

The existing header search now loads a cross-domain search projection only when a query exists. Search covers Stories, Intelligence, Opportunities, Agents, Strategies, Decisions, Experiments, Analytics, Distribution, Memory, Scenarios, AI Cost, AI Control, and Settings. It can locate and navigate only; it cannot execute or mutate.

The service chunk is loaded through a dynamic import so cross-phase fixtures are not added eagerly to every route's initial bundle.

### Global activity

The activity center projects deterministic timestamps and source IDs from existing strategy history, autonomy audit, experiment learning, memory conflict, and Growth evidence. Every event has domain, severity, status, provenance, and execution reality. No event is represented as live.

### Cross-system loop

The operating model visualizes Observe → Understand → Discover → Recommend → Decide → Execute → Measure → Learn → Remember → Next Strategy. Execute is explicitly unavailable; other stages separate capability state from execution reality.

### Capability and health

The health matrix separates capability availability from telemetry and execution reality across Frontend OS, Agent Workforce, Distribution, Analytics, Strategy, Autonomy, Memory, AI Economics, and External Providers. It does not equate simulation with uptime.
