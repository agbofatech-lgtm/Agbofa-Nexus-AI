# Fast-Track Readiness Pipeline

**Status:** Active for implementation units after IMP-001  
**Purpose:** Reduce repeated manual review by reusing certified baseline evidence and focusing on unit-specific exceptions.  

## Flow

```text
Implementation Card
  ↓
Baseline Evidence Certificate
  ↓
Automated Gate Matrix
  ↓
Exception Check
  ↓
Targeted Review if Needed
  ↓
READY or BLOCKED
  ↓
IAG Evaluation
```

## Rules

1. Do not re-prove unchanged baseline controls manually.
2. Review only new, changed, or unit-specific evidence.
3. Any exception must be documented and dispositioned.
4. Eligibility is not authorization.
5. IAG authorization remains mandatory before implementation.
