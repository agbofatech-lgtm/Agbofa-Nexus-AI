# Canonical Entity Registry

**Project:** Agbofa Nexus AI — Autonomous AI Media Company Platform  
**Purpose:** Assign stable canonical identifiers to major platform artifacts across documentation, implementation, testing, and deployment.  
**Status:** Scaffold created; awaiting approved source documentation intake.

## Registry Rules

1. Every major artifact must receive a permanent canonical ID before implementation.
2. IDs must remain stable across documentation, code, tests, deployment artifacts, and release reports.
3. Entity names must match the approved documentation exactly.
4. If duplicate or conflicting names are found, apply the Never Guess Rule and record the issue.
5. No service, API, database, event, workflow, UI screen, or AI agent may be implemented without a registry entry and source reference.
