# Security Policy

Security-sensitive work must preserve the Agbofa Nexus AI governance process.

## Reporting

Report security concerns through the designated security issue process and include affected services, APIs, source citations, and decision records.

## Required Controls

- No hardcoded secrets.
- Authentication and authorization at every boundary.
- Source and decision traceability for security-impacting changes.
- Governance validation before merge.
- Human review for security-sensitive implementation work.
