# API Contracts

This directory is the single source of truth for API contracts.

## Structure

- `protobuf/` — gRPC service definitions.
- `openapi/` — REST API definitions.
- `asyncapi/` — Kafka/event contracts.
- `json-schema/` — JSON schemas.
- `gen/` — generated code; do not edit manually.

No production API contract is added without source citation, registry entry, traceability, and implementation-unit authorization.
